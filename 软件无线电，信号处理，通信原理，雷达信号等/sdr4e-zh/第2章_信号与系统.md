# 第2章 信号与系统

SDR是信号处理的一个特定应用领域，每个从事SDR开发的人员不仅需要扎实的信号与系统基础，还需要掌握射频和模拟基带处理。本章涵盖线性时不变（LTI）信号与系统、模拟处理以及射频的诸多方面，这些构成了后续章节的基础。不要求读者逐一深入每个主题，但如果某个简短主题对你来说是全新的，建议参阅这些学科更全面的书籍。

## 2.1 时域与频域

时域和频域是表示同一信号的两种不同方式。傅里叶变换以其最初提出者——法国数学家和物理学家让-巴普蒂斯特·约瑟夫·傅里叶命名，是这两种表示之间的数学关系。如果信号在一个域中被修改，它在另一个域中也会发生变化，尽管通常变化方式不同。例如，时域中的卷积等价于频域中的乘法。其他数学运算，如加法、缩放和移位，在对应域中也有匹配的运算。这些关系称为傅里叶变换的性质，描述了一个域中的数学变化如何导致另一个域中的数学变化。

傅里叶变换只是描述信号的另一种方式。例如，研究吉布斯现象——即如果以特定的频率/相位/幅度组合叠加正弦波，可以逼近方波——可以用数学公式(2.1)表示，如图2.1所示。

$$x(t) = \sin(t) + \frac{\sin(3t)}{3} + \frac{\sin(5t)}{5} + \cdots = \sum_{n=1}^{\infty} \frac{\sin(n \times t)}{n}; \quad n = \text{奇数} \tag{2.1}$$

当我们沿着与频率轴垂直的时间轴观察信号时，我们观察的是时域。由于我们与频率轴垂直，因此不容易看出正弦波的频率。当我们变换域并沿着与时间轴垂直的频率轴观察现象时，我们观察的是频域或傅里叶域。我们可以轻易分辨信号的幅度和频率，但失去了时间方面的信息。两种视图表示的是同一信号，只是通过变换从不同的域进行观察。

### 2.1.1 傅里叶变换

傅里叶变换家族包括四个成员：傅里叶变换、傅里叶级数、离散傅里叶变换（DFT）和离散时间傅里叶变换（DTFT）。通常所说的FFT（快速傅里叶变换）及其逆变换IFFT，是DFT的一种特定实现。

x(t)的傅里叶变换定义为[1]：

$$X(\omega) = \int_{-\infty}^{\infty} x(t)e^{-j\omega t}dt \tag{2.2}$$

其中t是时域中的时间变量（单位为秒），ω是频域中的频率变量（单位为弧度/秒）。

对X(ω)应用类似的变换得到逆傅里叶变换[1]：

$$x(t) = \int_{-\infty}^{\infty} X(\omega)e^{j2\pi\omega t}d\omega \tag{2.3}$$

其中我们将x(t)写为复指数的加权和。

上述傅里叶变换对可以表示为[2]：

$$x(t) \stackrel{F}{\leftrightarrow} X(\omega) \tag{2.4}$$

其中符号$\stackrel{F}{\leftrightarrow}$左侧是傅里叶变换前的信号，右侧是傅里叶变换后的信号。表2.1总结了研究SDR频域时常用的若干傅里叶变换性质，供参考。

### 2.1.2 DFT的周期性

与其他三种傅里叶变换不同，DFT将时域和频域信号都视为周期性的（它们无限重复）。这可能令人困惑且不便，因为许多信号处理应用中使用的大多数信号并不是周期性的。然而，如果你想使用DFT（及其快速实现FFT），就必须遵循DFT对世界的看法。

图2.2展示了时域信号的两种不同解释。首先观察上方的信号，时域被视为N个点。这代表了SDR通常如何采集信号——通过一个N点的缓冲区。例如，这128个采样可能是以固定时间间隔对某个模拟信号采样获得的。采样0与采样127是不同且分离的，因为它们是在不同时间采集的。从信号的形成方式来看，没有理由认为信号左侧的采样与右侧的采样有任何关联。

遗憾的是，DFT并不这样看待事物。如图2.2下半部分所示，DFT将这128个点视为一个无限长周期信号的单个周期。这意味着采集信号的左侧连接到重复信号的右侧。同样，采集信号的右侧连接到相同周期的左侧。这也可以理解为采集信号的右侧环绕并连接到其左侧。在这种视图下，采样127紧邻采样0，就像采样43紧邻采样44一样。这被称为循环性，与将信号视为周期性是等价的。这就是为什么在应用FFT之前需要对信号捕获预加窗函数[3]——窗函数与信号相乘，通过将不连续点强制为零来消除它们[4]。

### 2.1.3 快速傅里叶变换

计算DFT有多种方法，例如求解联立线性方程或相关法。FFT是计算DFT的另一种方法。虽然它产生的结果与其他方法相同，但效率高得令人难以置信，通常将计算时间减少多个数量级。

虽然FFT只需要几十行代码，但它是信号处理中较为复杂的算法之一，其内部工作细节留给专门研究这类问题的人。只要理解它的工作原理，你就可以轻松使用现有的、经过验证的FFT例程[4,5]，而无需完全理解内部工作机制。

使用图2.3所示的通用测试装置进行FFT分析。FFT的频谱输出是频域中的一系列M/2个点（M是FFT的大小，即存储在缓冲存储器中的采样数）。点之间的间隔为fs/M，覆盖的总频率范围为DC到fs/2，其中fs是采样率。每个频率仓的宽度（有时称为FFT的分辨率）为fs/M。

图2.4展示了使用亚德诺ADIsimADC®程序对理想12位ADC的FFT输出。注意，FFT的理论噪声底等于理论信噪比（SNR）加上FFT处理增益10log₁₀(M/2)。重要的是要记住，SNR计算中使用的噪声值是扩展到整个奈奎斯特带宽（DC到fs/2）的噪声，但FFT的作用类似于一个带宽为fs/M的窄带频谱分析仪，在频谱上扫描。这具有将噪声压低一个等于处理增益的量的效果——与收窄模拟频谱分析仪带宽的效果相同。

FFT输出可以像模拟频谱分析仪一样用于测量数字化信号的各种谐波和噪声分量的幅度。输入信号的谐波可以通过其在频谱中的位置与其他失真产物区分开来。

## 2.2 采样理论

连续时间模拟信号可以通过采样和量化转换为离散时间数字信号，如图2.5所示，其中连续模拟输入信号xₐ(t)被转换为离散数字输出信号x[n]。采样是将连续时间信号转换为离散时间信号的过程，通过在离散时间时刻获取连续时间信号的采样来实现[1]。量化过程将采样幅度转换为数字格式。2.2.1节将介绍一种常用的采样方法——均匀采样。

类似地，离散时间信号也可以通过重建转换为连续时间信号。然而，重建并不总是成功的。有时，重建的信号与原始信号不同。因为对于给定的采样信号，它可以表示无限多个能够拟合到相同量化采样点的不同连续时间信号。然而，如果采样满足某些准则，信号可以无信息损失地重建。这个准则称为奈奎斯特采样定理，将在2.2.3节和2.5.1节中介绍。

### 2.2.1 均匀采样

将模拟信号采样为数字表示有多种方法。然而，如果我们将采样间隔指定为常数Ts，就得到了最广泛使用的采样方式，称为均匀采样或周期采样。使用这种方法，我们每隔Ts秒获取连续时间信号的采样，可以定义为

$$x[n] = x(nT_s), \quad -\infty < n < \infty \tag{2.5}$$

其中x(t)是输入连续时间信号，x[n]是输出离散时间信号，Ts是采样周期，fs = 1/Ts是采样频率。

均匀采样操作的等效模型如图2.6(a)所示，其中连续时间信号x(t)与冲激串p(t)相乘形成采样信号xₛ(t)，可以定义为

$$x_s(t) = x(t)p(t) \tag{2.6}$$

其中信号p(t)称为采样函数。

采样函数被假设为一系列窄脉冲，取值为0或1。因此，当p(t)=1时xₛ(t)=x(t)，当p(t)=0时xₛ(t)=0。由于p(t)仅在时间时刻Ts为1，因此得到的xₛ(t)=x(nTs)=x[n]，这证明了这确实是均匀采样操作的等效模型。这个模型将帮助我们在2.2.2节中获得均匀采样的频域表示。

### 2.2.2 均匀采样的频域表示

由于在频域中推导奈奎斯特采样定理更容易，本节我们尝试在频域中表示均匀采样过程。根据图2.6(b)，我们可以将采样函数p(t)定义为

$$p(t) = \sum_{k=-\infty}^{\infty} \delta(t - kT_s), \quad k = 0, 1, 2, \ldots \tag{2.7}$$

其中在时间时刻kTs，p(t)=1。根据[8]，p(t)是由狄拉克δ函数构成的狄拉克梳。

将(2.7)代入(2.6)得到

$$x_s(t) = x(t)p(t) = x(t)\sum_{k=-\infty}^{\infty} \delta(t - kT_s) \tag{2.8}$$

为了理解频域中的采样过程，我们需要对xₛ(t)进行傅里叶变换。根据表2.1中的频域卷积性质，时域中的乘法将导致频域中的卷积。因此，x(t)和p(t)的相乘将产生X(ω)和P(ω)的卷积：

$$X_s(\omega) = \frac{1}{2\pi} X(\omega) * P(\omega) \tag{2.9}$$

其中X(ω)是x(t)的傅里叶变换，P(ω)是p(t)的傅里叶变换。

狄拉克梳的傅里叶变换也是一个狄拉克梳[8]，即

$$P(\omega) = \frac{\sqrt{2\pi}}{T_s} \sum_{k=-\infty}^{\infty} \delta(\omega - k\frac{2\pi}{T_s}) = \frac{\sqrt{2\pi}}{T_s} \sum_{k=-\infty}^{\infty} \delta(\omega - k\omega_s) \tag{2.10}$$

其中ωₛ = 2πfₛ是采样频率。

与一系列δ函数脉冲在脉冲位置进行卷积，我们得到

$$X_s(\omega) = \frac{1}{\sqrt{2\pi}T_s} \sum_{k=-\infty}^{\infty} X(\omega - k\omega_s) \tag{2.11}$$

公式(2.11)告诉我们，均匀采样产生输入信号傅里叶变换的镜像，且镜像以采样频率fs为周期。

### 2.2.3 奈奎斯特采样定理

基于(2.11)，我们在频域上绘制原始信号x(t)和采样信号xₛ(t)的频谱，如图2.7所示。我们假设原始信号的带宽为[-fₕ, fₕ]，如图2.7(a)所示。目前我们不关注信号幅度，因此用A和Aₛ表示。假设采样频率为fs，则采样信号将在位置kfₛ处出现复制。为了从采样信号重建原始信号，我们将对采样信号应用低通滤波器，尝试从Xₛ(f)中提取n=0项，如图2.7(b)所示。因此，无差错重建要求Xₛ(f)在f=±fₛ处的频谱部分不与f=0处的频谱部分重叠。换言之，这要求fₛ - fₕ > fₕ，即fₛ > 2fₕ，这就引出了奈奎斯特采样定理。

奈奎斯特采样定理适用于带限信号，即信号x(t)在超过B Hz的频率处没有频谱分量[9]。即

$$X(\omega) = 0, \quad |\omega| > 2\pi B \tag{2.12}$$

奈奎斯特采样定理指出，带宽限制在B Hz的实信号x(t)，可以通过以R > 2B采样/秒的速率均匀采样而无差错地重建。这个最小采样频率Fₛ = 2B Hz称为奈奎斯特速率或奈奎斯特频率。对应的采样间隔T = 1/(2B)称为奈奎斯特间隔[1]。带宽限制在B Hz的信号，如果以低于奈奎斯特频率2B的速率采样（即以T > 1/(2B)的间隔采样），则称为欠采样。

当信号被欠采样时，其频谱具有重叠的频谱尾部或镜像，此时Xₛ(f)不再包含关于频谱的完整信息，也不再可能从采样信号恢复x(t)。在这种情况下，尾部频谱不会趋于零，而是折叠回视在频谱上。这种尾部的反转称为频谱折叠或混叠，如图2.7(c)所示[10]。

### 2.2.4 奈奎斯特区

奈奎斯特带宽本身定义为从DC到fs/2的频谱。然而，频谱被划分为无限多个奈奎斯特区，每个区的宽度等于0.5fs，如图2.9所示。频谱不会因为你对那些频率不感兴趣就结束。这意味着在采样器（或ADC）之前需要进行某种滤波，以移除奈奎斯特带宽之外但其混叠分量落入其中的频率分量。滤波器性能取决于带外信号距离fs/2有多近以及所需的衰减量。重要的是要注意，在理想采样器（或ADC）的输入端没有输入滤波的情况下，任何落在任何奈奎斯特区中奈奎斯特带宽之外的频率分量（无论是信号还是噪声）都将混叠回第一奈奎斯特区。因此，几乎所有采样ADC应用中都使用模拟抗混叠滤波器来移除这些不想要的信号。

### 2.2.5 采样率转换

在实际应用中，我们经常希望降低采样率，因为这减少了存储和计算需求。在许多情况下，我们更喜欢更高的采样率，因为它保持了保真度。采样率转换是改变由连续时间函数采样组成的序列中相邻元素之间时间间隔的过程的统称[10]。

**抽取**：降低采样率的过程称为抽取，通过忽略除每第D个采样之外的所有采样来实现。在时域中，可以定义为

$$y[n] = x[nD], \quad D = 1, 2, 3, \ldots \tag{2.13}$$

其中x[n]是原始信号，y[n]是抽取后的信号，D是抽取率。根据(2.13)，原始信号和抽取信号的采样率可以表示为

$$F_y = \frac{F_x}{D} \tag{2.14}$$

其中Fₓ是原始信号的采样率，Fᵧ是抽取信号的采样率。

由于以弧度为单位的频率变量ωₓ和ωᵧ可以通过采样率Fₓ和Fᵧ关联

$$\omega_x = 2\pi F T_x = 2\pi \frac{F}{F_x} \tag{2.15}$$

和

$$\omega_y = 2\pi F T_y = 2\pi \frac{F}{F_y} \tag{2.16}$$

由分配性质可得ωₓ和ωᵧ的关系为

$$\omega_y = D\omega_x \tag{2.17}$$

这意味着ωₓ的频率范围被拉伸因子D映射到ωᵧ的对应频率范围。

为了避免抽取序列y[n]的混叠，要求0 ≤ |ωᵧ| ≤ π。基于(2.17)，这意味着原始序列的频谱应满足0 ≤ |ωₓ| ≤ π/D。因此，在实际中，抽取通常是一个两步过程，由低通抗混叠滤波器和下采样器组成，如图2.10所示。低通抗混叠滤波器用于将下采样器输入信号x[n]的带宽限制为0 ≤ |ωₓ| ≤ π/D。

**插值**：提高采样率的过程称为插值，可以通过在信号的连续值之间插入（填充零）I-1个新采样来实现。在时域中，可以定义为

$$y[n] = \begin{cases} x[n/I] & n = 0, \pm I, \pm 2I, \ldots \\ 0 & \text{其他} \end{cases}, \quad I = 1, 2, 3, \ldots \tag{2.20}$$

其中x[n]是原始信号，y[n]是插值后的信号，I是插值率。

根据(2.20)，原始信号和插值信号的采样率可以表示为

$$F_y = I F_x \tag{2.21}$$

由于(2.15)和(2.16)在此也成立，可得ωₓ和ωᵧ的关系为

$$\omega_y = \frac{\omega_x}{I} \tag{2.22}$$

这意味着ωₓ的频率范围被压缩因子I映射到ωᵧ的对应频率范围。因此，插值后，将有x[n]频谱的I个复制，每个复制占据π/I的带宽。

由于y[n]中只有0 ≤ |ωᵧ| ≤ π/I范围内的频率分量是唯一的（即所有其他复制都与此相同），Y(ω)在ωᵧ = π/I以上的镜像应通过一个具有以下频率响应的低通滤波器来滤除：

$$H_I(\omega_y) = \begin{cases} C & 0 \leq |\omega_y| \leq \frac{\pi}{I} \\ 0 & \text{其他} \end{cases} \tag{2.23}$$

其中C是比例因子。

因此，在实际中，插值也是一个两步过程，由上采样器和低通滤波器组成，如图2.12所示。

## 2.3 信号表示

理解信号如何表示可以大大增强分析和设计数字通信系统的能力。我们需要多种便捷的数值数学框架来表示实际的射频、基带和噪声信号。我们通常有两种：包络/相位和同相/正交，两者都可以在时域和傅里叶域中表示。

### 2.3.1 频率变换

为了理解如何将信号从基带移到射频以及从射频移到基带，让我们更仔细地研究调制器和解调器。例如，在图2.18中我们看到一个非常经典的正交调制器。ADL5375接受两个差分基带输入和一个单端本振（LO），产生单端输出。LO接口产生两个正交（相位相差90°）的内部LO信号，这些信号用于驱动混频器，混频器 simply 将LO信号与输入相乘。

在数学上，这个混频过程将两个输入I_BB和Q_BB（我们记为I(t)和Q(t)）与频率为ω_c的LO相乘，并将结果相加以形成发射信号r(t)。用于乘以Q(t)的LO相移90°，使其与I(t)信号的乘法正交。因此，得到以下方程：

$$r(t) = I(t)\cos(\omega_c t) - Q(t)\sin(\omega_c t) \tag{2.25}$$

LO频率记为ω_c，因为它通常称为载波频率，它利用了同相（I(t)cos(ω_ct)）和正交（Q(t)sin(ω_ct)）分量之间的相位关系。因此，发射信号将包含两个分量，但表现为单个正弦波。

在接收机端，我们将通过类似但反向的过程将r(t)下混频回同相和正交基带信号。通过将具有第二个相移分量的相同LO应用于r(t)并经过低通滤波器，我们得到

$$I_r(t) = \text{LPF}\{r(t)\cos(\omega_c t)\} = \text{LPF}\{(I(t)\cos(\omega_c t) - Q(t)\sin(\omega_c t))\cos(\omega_c t)\} = \frac{I(t)}{2} \tag{2.26}$$

$$Q_r(t) = \text{LPF}\{r(t)\sin(\omega_c t)\} = \text{LPF}\{(-I(t)\cos(\omega_c t) + Q(t)\sin(\omega_c t))\sin(\omega_c t)\} = \frac{Q(t)}{2} \tag{2.27}$$

在实践中，发射机LO和接收机LO之间会有一些相位差，这可能导致r(t)的旋转。然而，I(t)和Q(t)之间的相位关系将始终保持。

### 2.3.2 复信号

将信号作为正交或复信号讨论是利用欧拉等人创建的数学构造来简化分析。我们尽量将信号称为同相（I）和正交（Q），因为这在学术上是正确的。如2.3.1节所述，同相（I）指与本振同相的信号部分，正交（Q）指与相移90°的LO同相的信号部分。

将I描述为实部、Q描述为虚部很方便，因为这启用了许多数学技术，但归根结底这只是一个构造。这种便利性的一个典型例子是由混频器执行的频率变换。我们从欧拉关系开始

$$e^{jx} = \cos(x) + j\sin(x) \tag{2.28}$$

其中我们可以将x定义为目标频率加时间。采用2.3.1节的约定但将I(t)和Q(t)重新定义为实部和虚部，我们得到

$$y(t) = I(t) + jQ(t) \tag{2.29}$$

现在，如果我们假设y(t)是频率为ωₐ的连续波（CW）单音用于说明，y(t)变为

$$y(t) = \cos(\omega_a t) + j\sin(\omega_a t) \tag{2.30}$$

现在应用(2.28)，我们可以将y(t)频移所需的频率ω_c：

$$y(t)e^{j\omega_c t} = [I(t)\cos(\omega_c t) - Q(t)\sin(\omega_c t)] + j[Q(t)\cos(\omega_c t) + I(t)\sin(\omega_c t)] = \cos((\omega_c + \omega_a)t) + j\sin((\omega_c + \omega_a)t) \tag{2.31}$$

现在，通过简单应用欧拉恒等式，我们的结果信号将存在于频率ωₐ + ω_c处。

## 2.4 信号度量与可视化

在工程师能够决定项目是否完成之前，他或她需要进行某种形式的验证。然而，鉴于通信系统的集成性质以及发射和接收链的深度，对其进行评估很复杂。如1.4节所述，通信系统可能具有除尺寸、重量、功耗和成本（SWaP-C）之外的各种度量。诸如误码率（BER）、数据吞吐量和距离等性能度量也只是顶层系统规范。正如我们为整个系统制定系统级规范一样，我们也为其他子系统和SDR构建模块制定规范和测量技术。这样，我们知道我们没有对特定组件进行过度设计或设计不足。然而，应始终在系统级考虑权衡，因为上游修改可能影响下游组件或实现。

### 2.4.1 SINAD、ENOB、SNR、THD、THD+N和SFDR

表2.2中列出了量化模拟动态性能的六种流行规范[6]。理解和使用这些测量将帮助你分析设计并确保你设计的东西最稳健。尽管大多数器件和系统制造商对这些规范采用了相同的定义，但仍存在一些例外。由于它们在比较器件和系统方面的重要性，不仅要理解具体规定了什么，还要理解规范之间的关系，这一点很重要。

- **无杂散动态范围（SFDR）**是信号均方根（RMS）值与最坏杂散信号RMS值之比，无论其落在频谱中的何处。最坏杂散可能是也可能不是原始信号的谐波。这通常在感兴趣的带宽上测量，假设为奈奎斯特带宽（除非另有说明；基带为DC到fs/2，复数（射频）转换器为-fs/2到fs/2，如Pluto SDR上的器件）。SFDR是通信系统中的重要规范，因为它代表了可以与大干扰信号（阻塞信号）区分开的最小信号值。SFDR通常绘制成信号幅度的函数，可以相对于信号幅度（dBc）或ADC满量程（dBFS）表示，如图2.21所示。MATLAB的sfdr函数以dBc为单位提供结果。对于接近满量程的信号，峰值频谱杂散通常由基波的前几次谐波之一决定。然而，当信号低于满量程几dB时，通常会出现不是输入信号直接谐波的其他杂散。这是因为系统传递函数的微分非线性在较小信号时通常占主导地位。因此，SFDR考虑所有失真源，无论其来源如何，是评估各种通信系统的有用工具。

- **总谐波失真（THD）**是基波信号RMS值与其谐波均方根平均值之比（通常只有前五次谐波是显著的）。ADC的THD通常也在输入信号接近满量程时规定，尽管可以在任何电平规定。

- **总谐波失真加噪声（THD+N）**是基波信号RMS值与其谐波加所有噪声分量（不包括DC）的均方根平均值之比。必须规定测量噪声的带宽。在FFT的情况下，带宽为DC到fs/2。（如果测量带宽为DC到fs/2（奈奎斯特带宽），则THD+N等于SINAD）。

- **信纳比（SINAD，或S/(N+D)）**是信号RMS幅度与所有其他频谱分量（包括谐波，但不包括DC）的均方根（RSS）平均值之比。SINAD是模拟系统整体动态性能的良好指标，因为它包含了构成噪声和失真的所有分量。SINAD通常针对各种输入幅度和频率进行表征。对于给定的输入频率和幅度，只要两者的噪声测量带宽相同（奈奎斯特带宽），SINAD等于THD+N。

- **信噪比（SNR，有时称为无谐波SNR）**从FFT数据计算的方式与SINAD相同，只是计算中排除了信号谐波，只留下噪声项。在实践中，只需要排除前五次谐波，因为它们占主导地位。SNR曲线在高输入频率时会下降，但通常不像SINAD那样迅速，因为排除了谐波项。

### 2.4.2 眼图

虽然说起来很明显，但时域图用于观察电信号随时间的变化。可以凭经验确定许多现象，如幅度、频率、上升时间、时间间隔、失真、噪声底等，以及这些特性如何随时间变化。在电信中，眼图（也称为眼图模式）是一种时域显示，其中来自接收机的数字数据信号被重复采样并施加到垂直输入，而数据速率用于触发水平扫描[9]。它之所以称为眼图，是因为该模式看起来像一对轨道之间的一系列眼睛。

通过分析显示可以得出几个系统性能度量，特别是码间干扰（ISI）的程度。随着眼睛闭合，ISI增加；随着眼睛张开，ISI减少。此外，如果信号太长、太短、与系统时钟同步不良、太高、太低、噪声太大、变化太慢，或者有太多下冲或过冲，都可以从眼图中观察到。例如，图2.22展示了噪声正交相移键控（QPSK）信号的典型眼图模式。

由于眼图传达和测量了许多不同类型的关键数据，这可以帮助量化算法或系统的工作效果。两个关键测量是垂直张开度（BER阈值点之间的距离）和眼高（眼电平之间的最小距离）。眼睛中较大的垂直和水平张开度总是更好。

## 2.5 SDR接收技术

现代通信的研究在考虑模拟和数字域时保持着巨大的二元性。两个域都被高效且高速地处理。然而，模拟信号保持着无限精度的视角，但由于其本质，将始终包含某种程度的随机性。另一方面，数字信号是精确且精确定义的，但受计算复杂性的边界及其基础的限制。数字通信必须有效地管理这两个世界，以设计点之间的稳健链路。因此，两个域高度相互依赖。

即使在当今数字信号处理（DSP）器件丰富且具有成本效益的世界中，模拟信号也经过处理、放大、滤波，然后才由ADC转换为二进制形式。ADC的输出只是模拟信号的二进制表示，并在从FPGA到通用CPU的多个计算单元上进行处理。处理之后，从数字化信号获得的信息可以使用数模转换器（DAC）转换回模拟形式。SDR物理恢复的信号最初是时变电场，它在接收天线中感应出电流，并在接收机处产生可检测的电压。另一方面，SDR的发射是施加到天线上的时变电压，这导致电子作为向外辐射的电场运动。

### 2.5.1 奈奎斯特区

在2.2.3节中，我们考虑了基带采样的情况（即所有感兴趣的信号都在第一奈奎斯特区内）。图2.25展示了这种情况，其中采样信号的频带限于第一奈奎斯特区，原始频带的镜像出现在每个其他奈奎斯特区中。考虑图2.25 B所示的情况，其中采样信号频带完全位于第二奈奎斯特区内。对第一奈奎斯特区之外的信号进行采样的过程通常称为欠采样或谐波采样。注意，落入第一奈奎斯特区的镜像包含原始信号中的所有信息，除了其原始位置。

图2.25展示了限制在第三奈奎斯特区的采样信号。注意，落入第一奈奎斯特区的镜像没有频率反转。事实上，采样信号频率可以位于任何唯一的奈奎斯特区，落入第一奈奎斯特区的镜像仍然是准确的表示。此时我们可以清楚地重申奈奎斯特准则：

信号必须以等于或大于其带宽两倍的速率采样，以保留所有信号信息。

注意，没有提到采样信号频带在频谱中相对于采样频率的绝对位置。唯一的约束是采样信号频带必须限制在单个奈奎斯特区（即信号不得与fs/2的任何倍数重叠）。事实上，这是抗混叠滤波器的主要功能。在第一奈奎斯特区以上对信号进行采样在通信中变得流行，因为该过程等同于模拟解调。直接对中频信号采样然后使用数字技术处理信号正变得常见做法，从而消除了对中频解调器和滤波器的需求。然而，随着中频频率变高，ADC的动态性能要求（带宽、线性度、失真等）变得更加关键，因为性能必须在第二或第三奈奎斯特区足够，而不仅仅是基带。这对许多设计用于处理第一奈奎斯特区信号的ADC提出了问题。因此，适用于欠采样应用的ADC必须在高阶奈奎斯特区保持动态性能。

### 2.5.2 定点量化

与理想N位数据转换器相关的唯一误差（DC或AC）是与采样和量化过程相关的误差。理想转换器在数字化信号时的最大误差为±1/2 LSB，恰好在两个数字值之间。这从理想N位ADC的传递函数中显而易见，如图2.26所示。对于跨越超过几个LSB的任何AC信号，量化误差可以近似为一个不相关的锯齿波形，其峰峰值幅度为q（LSB的权重）。虽然这种分析不精确，但对于大多数应用来说足够准确。

作为时间函数的量化误差如图2.27所示。同样，简单的锯齿波形为分析提供了足够准确的模型。锯齿误差的方程为

$$e(t) = st, \quad -\frac{q}{2s} < t < \frac{q}{2s} \tag{2.33}$$

其中s是量化噪声的斜率。e(t)的均方值可以写为

$$\overline{e^2(t)} = \frac{s}{q} \int_{-q/2s}^{q/2s} (st)^2 dt = \frac{q^2}{12} \tag{2.34}$$

(2.34)的平方根，即RMS噪声量化误差，近似为高斯分布，或多或少均匀地扩展在DC到fs/2的奈奎斯特带宽上。

现在可以假设满量程输入正弦波v(t)来计算理论SNR

$$v(t) = \frac{q2^N}{2}\sin(\omega t) \tag{2.35}$$

首先计算输入信号的RMS值，定义为

$$\sqrt{\overline{v(t)^2}} = \frac{q2^N}{2\sqrt{2}} \tag{2.36}$$

因此，理想N位转换器的RMS信噪比为

$$\text{SNR} = 20\log_{10}\left(\frac{\text{满量程输入RMS}}{\text{量化噪声RMS}}\right) = 20\log_{10}\left(\frac{q2^N/(2\sqrt{2})}{q/\sqrt{12}}\right) \tag{2.37}$$

对(2.37)进行一些简化后，我们得到以dB为单位的SNR：

$$\text{SNR} = 20\log_{10}\left(\sqrt{\frac{3}{2}}2^N\right) = 6.02N + 1.76 \tag{2.38}$$

同样，这是针对DC到fs/2带宽的。在许多应用中，实际感兴趣的信号占据较小的带宽（BW）。例如，如果使用数字滤波滤除BW之外的噪声分量，则必须在方程中包含一个校正因子（称为处理增益），以解释SNR的相应增加。以大于信号带宽两倍的速率对信号进行采样的过程通常称为过采样。事实上，过采样结合量化噪声整形和数字滤波是Σ-Δ转换器的关键概念，将在2.5.4节讨论。

### 2.5.3 位数、成本、功耗等的设计权衡

关于两个接收链（I/Q）最重要的是要记住ADC本身量化的影响。也就是说，N位字表示2ᴺ个可能状态之一，因此N位ADC（具有固定参考）只能有2ᴺ个可能的数字输出。数据转换器的分辨率可以用几种不同的方式表示：最低有效位（LSB）的权重、满量程的百万分之几（ppm FS）和毫伏（mV）。不同的器件，即使来自同一制造商，也会有不同的规定。因此，转换器用户必须学会在不同类型的规范之间转换，才能成功比较器件。

虽然24位转换器具有-144 dB性能听起来可能是个好主意，但从功耗或速度角度来看并不实际。尽管存在许多24位ADC，但它们不是宽带的，例如AD7177是一款最先进的32位转换器，输出数据速率限制在5 SPS到10 kSPS，不适用于SDR，但却是温度和压力测量、色谱或称重秤等应用的绝佳解决方案[12]。另一方面，确实存在更高速的ADC，例如AD9208，这是一款双通道14位3 GSPS ADC，提供70 dBFS的SFDR和9 GHz模拟输入全功率带宽（第六奈奎斯特频带）。然而，AD9208的功耗超过3W，超过了Pluto SDR通过USB流式传输数据时的整个功耗[13]。尽管如此，基于AD9208的系统可以提供高达12 GB/s的数据，这比软件能处理的数据更多，需要FPGA内部的定制信号处理硬件。

### 2.5.4 Σ-Δ模数转换器

Σ-Δ（Sigma-Delta）模数转换器（ADC）已经为人所知超过50年，但直到最近才存在以低成本制造单片集成电路的技术（高密度数字VLSI）。它们现在用于许多需要低成本、中等带宽、低功耗、高分辨率ADC的应用中。关于Σ-Δ ADC的架构和理论已有无数描述，但大多数从深入的数学描述开始，从积分开始并继续展开。由于这不是一本ADC教科书，我们将尽量避免数学推导，而是基于本章前面涵盖的主题来探索事物。

Σ-Δ ADC没有什么特别难以理解的。Σ-Δ ADC包含非常简单的模拟电子器件（比较器、电压基准、开关以及一个或多个积分器和模拟求和电路）和数字计算电路。该电路包含一个滤波器，通常但不总是低通滤波器。不需要精确知道滤波器如何工作就能理解它的作用。要理解Σ-Δ ADC如何工作，需要熟悉过采样、量化噪声整形、数字滤波和抽取的概念，所有这些都是本章前面涵盖的主题。

## 2.6 SDR的数字信号处理技术

DSP是一个始终处于数学复杂性、计算性能和日益增长的移动性边缘的领域，影响着通信、医学成像、雷达、娱乐甚至科学探索。然而，所有这些领域都依赖于将模拟信息转换为数字表示并通过某种机制处理该数据的概念。为此，工程师和科学家依赖于包括C和Verilog在内的通用工具和语言，所有这些都能以高效和程序化的方式操作数字信息。无论语言如何，许多重要的DSP软件问题都是特定于硬件的，例如截断误差、位模式以及处理器的计算速度和效率[14]。目前，我们将主要忽略这些问题，专注于信号处理的算法问题，并讨论常用算法。

### 2.6.1 离散卷积

卷积是将两个信号组合形成第三个信号的数学工具，构成了所有DSP的基础。使用冲激分解策略，系统由一个称为冲激响应的信号描述。卷积很重要，因为它关联了三个感兴趣的信号：输入信号、输出信号和冲激响应。

图2.36展示了应用于线性系统的卷积表示法。离散采样输入信号x[n]进入具有冲激响应h[n]的线性系统，产生输出信号y[n]。用文字表达，输入信号与冲激响应的卷积等于输出信号。如(2.41)所示，卷积由*运算符表示。遗憾的是，大多数编程语言（如MATLAB）使用星号表示乘法，并使用特殊函数（如MATLAB的conv函数）表示卷积。计算机程序中的星号表示乘法，而这里的星号表示卷积。

从根本上说，卷积的数学由若干乘法和加法组成。如果x[n]是从数据采样0到N-1的N点信号，h[n]是从0到M-1的M点信号，则两者的卷积y[n] = x[n] * h[n]是从0到N+M-2的N+M-1点信号，由下式给出

$$y[i] = \sum_{j=0}^{M-1} h[j] \times x[i-j] = h[i] * x[i] \tag{2.41}$$

这个方程称为卷积和。它允许输出信号中的每个点独立于输出信号中的所有其他点进行计算。索引i确定正在计算输出信号中的哪个采样。

### 2.6.2 相关

互相关和自相关是SDR中的两个重要概念。互相关是两个序列相似性的度量，作为一个相对于另一个位移的函数。

相关的概念最好通过例子来呈现。图2.38展示了雷达系统的关键要素。专门设计的天线在选定方向上发射短脉冲无线电波能量。如果传播的波击中物体（如此图中的直升机），一小部分能量被反射回位于发射机附近的无线电接收机。发射脉冲是我们选择的特定形状，例如此示例中所示的三角形。接收信号将由两部分组成：(1)发射脉冲的移位和缩放版本，以及(2)由干扰无线电波、电子器件中的热噪声等引起的随机噪声。由于无线电信号以已知速率（光速）传播，发射和接收脉冲之间的移位直接衡量了到被检测物体的距离。挑战在于确定信号在另一个信号中出现的最佳方式。相关是这个问题的解决方案。

相关是一种与卷积非常相似的数学运算。就像卷积一样，相关使用两个信号产生第三个信号。这第三个信号称为两个输入信号的互相关。如果一个信号与自身相关，则结果信号称为自相关。互相关信号中每个采样的幅度是接收信号在该位置与目标信号相似程度的度量。这意味着对于接收信号中存在的每个目标信号，互相关信号中都会出现一个峰值。换言之，当目标信号与接收信号中的相同特征对齐时，互相关的值最大化。

在随机噪声中检测已知波形的最优技术之一是相关。也就是说，使用相关时峰值高于噪声的程度高于任何其他线性系统所能产生的程度。（严格来说，它仅对随机白噪声是最优的。）使用相关检测已知波形通常称为匹配滤波。更多内容见4.7.1节。

对于离散函数f和g，互相关定义为

$$(f \star g)[n] = \sum_{j=-\infty}^{\infty} f^*[m] \times g[m+n] \tag{2.42}$$

其中h*表示h的复共轭。函数f(t)和g(t)的互相关等价于f*(-t)和g(t)的卷积。即

$$(f \star g)[n] = f^*(-t) * g(t) \tag{2.43}$$

不要让卷积和相关之间的数学相似性迷惑你；它们代表非常不同的信号处理概念。卷积是系统输入信号、输出信号和冲激响应之间的关系。相关是在噪声背景中检测已知波形的方法。相似的数学是一个方便的巧合，允许算法优化。

### 2.6.3 Z变换

在2.1.1节中，我们介绍了处理连续时间信号频域的傅里叶变换。由于本节我们专注于涉及离散时间信号的数字滤波器设计，我们需要引入一种新的变换类型——Z变换。

离散时间信号x[n]的Z变换定义为幂级数：

$$X(z) = \sum_{n=-\infty}^{\infty} x[n]z^{-n} \tag{2.44}$$

其中z是复变量[1]。

Z变换用于分析离散时间系统。其连续时间对应物是拉普拉斯变换，定义如下：

$$X(s) = \int_{-\infty}^{\infty} x(t)e^{-st}dt \tag{2.45}$$

其中t是时域中的时间变量（秒），s = σ + jω是复变量。当沿jω轴计算（即σ = 0）时，拉普拉斯变换简化为(2.2)中定义的傅里叶变换。因此，拉普拉斯变换将傅里叶变换从实线（频率轴jω）推广到整个复平面。

根据2.2.2节，我们知道如果连续时间信号x(t)被均匀采样，其采样信号xₛ(t)可以表示为

$$x_s(t) = \sum_{n=-\infty}^{\infty} x(nT)\delta(t - nT) \tag{2.46}$$

其中T是采样间隔。如果我们对两边取拉普拉斯变换，我们将得到

$$X_s(s) = \int_{-\infty}^{\infty} x_s(t)e^{-st}dt = \int_{-\infty}^{\infty} \left(\sum_{n=-\infty}^{\infty} x(nT)\delta(t - nT)\right)e^{-st}dt \tag{2.47}$$

由于积分和求和都是线性算子，我们可以交换它们的顺序。然后，基于δ函数的采样性质，我们可以进一步得到

$$X_s(s) = \sum_{n=-\infty}^{\infty} x(nT)\left(\int_{-\infty}^{\infty} \delta(t - nT)e^{-st}dt\right) = \sum_{n=-\infty}^{\infty} x(nT)e^{-snT} \tag{2.48}$$

令z = e^{sT}，即s = (1/T)ln z，则(2.48)变为

$$X(z) = \sum_{n=-\infty}^{\infty} x(nT)z^{-n} \tag{2.49}$$

由于T是采样间隔，x(nT) = x[n]。上式可以进一步写为

$$X(z) = \sum_{n=-\infty}^{\infty} x[n]z^{-n} \tag{2.50}$$

这正是(2.44)中Z变换的定义。因此，Z变换和拉普拉斯变换可以通过以下方式连接

$$z = e^{sT} \tag{2.51}$$

或

$$s = \frac{1}{T}\ln(z) \tag{2.52}$$

根据(2.44)，我们知道Z变换是z⁻¹的级数。实际上，除非级数收敛，否则Z变换没有意义。给定有限幅度序列x[n]，使其Z变换收敛的所有z值的集合称为收敛域（ROC）。基于级数理论，这些z值必须满足

$$\sum_{n=-\infty}^{\infty} |x[n]z^{-n}| < \infty \tag{2.53}$$

### 2.6.4 数字滤波

在进行信号处理时，我们通常需要去除噪声并提取有用信号。这个过程称为滤波，所使用的器件称为滤波器，它根据施加在其输入端的对象的某些属性来区分什么可以通过。典型的滤波器是选频电路。如果噪声和有用信号具有不同的频率分布并同时出现在滤波器输入端，则通过应用该电路，噪声将被衰减甚至消除，而有用信号被保留。

滤波器可以从不同方面分类。例如，根据频率响应，滤波器可以分为低通、高通、带通和带阻。根据处理的信号，滤波器可以分为模拟滤波器或数字滤波器[1]。具体而言，模拟滤波器处理连续时间信号，而数字滤波器处理离散时间信号。本节将专注于数字滤波器。

由于理想的砖墙滤波器在实践中无法实现，我们将注意力限制在由差分方程指定的线性时不变系统类别[1]：

$$y[n] = -\sum_{k=1}^{N} a_k y[n-k] + \sum_{k=0}^{M} b_k x[n-k] \tag{2.60}$$

其中y[n]是当前滤波器输出，y[n-k]是先前滤波器输出，x[n-k]是当前或先前滤波器输入。该系统具有以下频率响应：

$$H(z) = \frac{\sum_{k=0}^{M} b_k e^{-z}}{1 + \sum_{k=1}^{N} a_k e^{-z}} \tag{2.61}$$

其中{aₖ}是滤波器的反馈系数，对应于滤波器的极点；{bₖ}是滤波器的前馈系数，对应于滤波器的零点；N是滤波器的阶数。

基本的数字滤波器设计问题是通过适当选择系数{aₖ}和{bₖ}，用具有(2.61)频率响应的系统来逼近任何理想频率响应特性[1]。

数字滤波器有两种基本类型：有限冲激响应（FIR）和无限冲激响应（IIR）滤波器。当由单位采样δ[n]激励时，系统的冲激响应h[n]可能持续有限时间，如图2.41(a)所示，或者甚至在输入施加之前就永远持续，如图2.41(b)所示。在前一种情况下，系统是有限冲激响应的；在后一种情况下，系统是无限冲激响应的。

长度为M的FIR滤波器，输入为x[n]，输出为y[n]，可以用差分方程描述[1]：

$$y[n] = b_0x[n] + b_1x[n-1] + \cdots + b_{M-1}x[n-M+1] = \sum_{k=0}^{M-1} b_k x[n-k] \tag{2.62}$$

其中滤波器没有反馈系数{aₖ}，因此H(z)只有零点。

IIR滤波器已在(2.60)中定义，它具有一个或多个非零反馈系数{aₖ}。因此，一旦滤波器被冲激激励，就总是有输出。

#### 2.6.4.1 案例研究：级联积分梳状滤波器

级联积分梳状滤波器（CIC滤波器）在SDR硬件中发挥着重要作用。它们由Eugene B. Hogenauer发明，是一类用于多速率信号处理的FIR滤波器。CIC滤波器在插值和抽取中找到应用。然而，与大多数FIR滤波器不同，它在架构中内置了抽取器或插值器[16]。

CIC滤波器由一个或多个积分器和梳状滤波器对组成。在抽取CIC的情况下，输入信号通过一个或多个级联积分器，然后是下采样器，再然后是一个或多个梳状部分，其数量等于积分器的数量。插值CIC只是这种架构的反向，下采样器被上采样器取代，如图2.42所示。

CIC滤波器的特性包括线性相位响应以及仅使用延迟和加减法。换言之，它不需要乘法运算，因此适合硬件实现。

#### 2.6.4.2 案例研究：FIR半带滤波器

FIR半带滤波器在进行插值/抽取时也广泛用于多速率信号处理应用。半带滤波器以多相形式高效实现，因为其大约一半的系数等于零。半带滤波器有两个重要特性：通带和阻带纹波必须相同，通带边缘和阻带边缘频率与半带频率fs/4等距。

例如，Pluto SDR在接收和发射链中有多个可编程半带滤波器。RX HB3/DEC3提供两种不同固定系数抽取滤波器之间的选择，抽取因子为2、3或1（旁路）。滤波器的输入（ADC的输出）为24或16位值。

从ADC输出并由数字信号处理算法处理、最终由数模转换器处理的信号不需要波形是平滑的。因此，它们经历的是图2.45(a)所示的情况。信号不是连续的，也不是平滑的。只要理解了2.2.3节中描述的主题并且不违反奈奎斯特采样定理，这就足够了。唯一成为问题的时候是当我们想实际将采样数据转换回连续模拟域时。连续模拟域的带宽是无限的，不会在fs/2处停止，如图2.45(b)所示。当考虑超出数字限制的时域数据时，信号的混叠仍然可见。

### 2.7.1 模拟重建滤波器

在2.5.4节中，讨论了过采样如何放宽对抗混叠滤波器的要求，以及Σ-Δ ADC如何具有这种固有优势。在基于DAC的系统中，插值的概念可以类似地与模拟重建滤波器一起使用。这在数字音频CD播放器中很常见，其中来自CD的数据基本更新速率约为44.1 kSPS。如2.2.5节所述，将零插入数据中，数据通过数字滤波器，从而将有效采样更新率提高到原始速率的四倍、八倍或十六倍。高过采样率将镜像频率移得更高，允许使用具有更宽过渡带的较不复杂的滤波器。

### 2.7.2 DAC

理论上，数模转换最简单的方法是从存储器中取出采样并将它们转换为冲激串。类似于2.2.2节中的采样函数，冲激调制器可以定义为

$$p(t) = \sum_{k=-\infty}^{\infty} \delta(t - kT) \tag{2.68}$$

其中对于t = kT，p(t) = 1；对于所有其他时间时刻，p(t) = 0。因此，冲激调制器之后的模拟脉冲串为

$$s_a(t) = s[n]p(t) = \sum_{k=-\infty}^{\infty} s(kT)\delta(t - kT) = \begin{cases} s(kT) & t = kT \\ 0 & t \neq kT \end{cases} \tag{2.69}$$

其中每个数字符号s[n]启动一个由符号值缩放的模拟脉冲。原始模拟信号可以通过将此冲激串通过截止频率等于采样率一半的低通滤波器来重建。

虽然这种方法在数学上很纯粹，但即使在现代电子器件中也很难生成所需的无限窄冲激脉冲。为了解决这个问题，几乎所有DAC都通过保持上一个值直到接收到另一个采样来工作。这称为零阶保持，是ADC期间使用的采样保持的DAC等价物。零阶保持在时域中产生阶梯外观，如图2.44(b)所示。

在频域中，零阶保持导致冲激串的频谱乘以sinc函数，由以下方程给出

$$H(f) = \left|\frac{\sin(\pi f/f_s)}{\pi f/f_s}\right| \tag{2.70}$$

如果你已经有这方面的背景，零阶保持可以理解为冲激串与宽度等于采样周期的矩形脉冲的卷积。这导致频域乘以矩形脉冲的傅里叶变换，即sinc函数。图2.47中的虚线展示了30 MHz和60 MHz DAC的sinc函数。从图2.47可以看出，sinc函数衰减通带中的信号。然而，系统中需要有东西通过零阶保持效应的倒数1/sinc(x)来补偿这种效应，或者简单地接受这种非理想性。许多人忽略了这个问题，但用Pluto SDR来做非常简单。允许用户轻松地以非常平坦的通带进行发射。

### 2.7.3 数字脉冲成形滤波器

为了理解为什么我们需要在所有无线电设计中包含数字脉冲成形滤波器，将展示一个简短的例子。相移键控（PSK）是一种简单但常见的数字调制方案，通过改变参考信号的相位来传输数据。这如图2.48(a)和2.48(d)所示，其中展示了载波的时域和频域。频率非常窄，应该容易传输。

图2.48(b)和2.48(e)中所示的1和0交替比特流造成了问题。检查这一点，我们观察到方波具有无限的频率信息，这在实际考虑中非常难以传输。

当我们将图2.48(a)中的载波与图2.48(b)中的比特流相乘以尝试通过天线传输此数据时，结果如图2.48(c)和2.48(f)所示，这是一个在连续时间模拟域中具有无限带宽的信号。不仅我们难以传输，相邻射频信道中最近的邻居也不会喜欢。

回到我们的冲激数学模型，(2.70)表明，如果没有数字脉冲成形滤波器，这些脉冲sₐ(t)将立即通过信道传输。理论上，给定接收机侧无限带宽，我们应该能够获得相同的脉冲串，尽管有一些延迟。然而，在现实中，由于有限带宽和相邻符号之间的干扰，我们实际上无法恢复这样的信号。

相邻符号可能相互干扰有两种情况：当脉冲形状宽于单个符号间隔T时，以及当存在非理想信道使附近脉冲弥散导致它们重叠时。这两种情况都称为码间干扰（ISI）[9]。

为了解决这些问题，引入了脉冲成形滤波器来对发射波形进行带限。

### 2.7.4 奈奎斯特脉冲成形理论

在通信系统中，通常有两个脉冲成形滤波器，一个在发射机侧，另一个在接收机侧，如图2.49所示，其中我们用h_T(t)和h_R(t)表示发射滤波器和接收滤波器的冲激响应。为简单起见，在考虑奈奎斯特脉冲成形理论时，我们通常使用等效信道的概念，它不仅包括信道本身，还包括两个脉冲成形滤波器。因此，等效信道的冲激响应为

$$h(t) = h_T(t) * h_C(t) * h_R(t) \tag{2.71}$$

现在，让我们考虑在什么条件下可以确保符号之间没有码间干扰。等效信道的输入sₐ(t)已在(2.70)中定义。如前所述，每个模拟脉冲由符号值缩放，因此我们可以用另一种方式表达sₐ(t)：

$$s_a(t) = \sum a_k \delta(t - kT) \tag{2.72}$$

其中aₖ是第k个符号的值。它产生等效信道的输出y(t)，即

$$y(t) = s_a(t) * h(t) = \sum a_k [\delta(t - kT) * h(t)] = \sum a_k h(t - kT) \tag{2.73}$$

因此，给定特定的时间时刻，例如t = mT，其中m是常数，输入sₐ(t)为

$$s_a(mT) = \sum a_k \delta(mT - kT) = a_m \tag{2.74}$$

因此，输出y(t)变为

$$y(mT) = \sum a_k h(mT - kT) = a_0h(mT) + a_1h(mT - T) + \cdots + a_mh(mT - mT) \tag{2.75}$$

由于我们不想要来自其他符号的干扰，我们希望输出只包含aₘ项，即

$$y(mT) = a_mh(mT - mT) \tag{2.76}$$

此外，这意味着在时间时刻t = mT，我们需要有

$$h(mT - kT) = \begin{cases} C & k = m \\ 0 & k \neq m \end{cases} \tag{2.77}$$

其中C是某个非零常数。

如果我们将(2.77)推广到任何时间时刻t，我们可以得到如下奈奎斯特脉冲成形理论。一个脉冲在后续T间隔采样时刻不干扰其他脉冲的条件被形式化为：如果h(t)满足

$$h(t) = h(kT) = \begin{cases} C & k = 0 \\ 0 & k \neq 0 \end{cases} \tag{2.78}$$

对于所有整数k，则h(t)是奈奎斯特脉冲。

### 2.7.5 两种奈奎斯特脉冲

在本节中，我们将介绍两种重要的奈奎斯特脉冲：sinc脉冲和升余弦脉冲。考虑(2.78)时，我们能想到的最直接的脉冲是时间宽度小于T的矩形脉冲，或任何宽度小于T的脉冲形状。然而，矩形脉冲（和其他窄脉冲形状）的带宽可能太宽。窄脉冲形状不能有效利用频谱，但宽脉冲形状可能导致ISI，所以需要的是一个在时间上宽（在频率上窄）且同时满足(2.78)中奈奎斯特条件的信号[9]。

在数学中，sinc函数定义为

$$\text{sinc}(x) = \frac{\sin(\pi x)}{\pi x} \tag{2.79}$$

如图2.50所示，当变量x取整数值k时，sinc函数的值为

$$\text{sinc}(k) = \begin{cases} 1 & k = 0 \\ 0 & k \neq 0 \end{cases} \tag{2.80}$$

换言之，归一化sinc函数的零交叉发生在非零整数值处。

sinc函数的另一个重要性质是sinc脉冲是矩形信号的逆傅里叶变换，如图2.51(a)所示。假设矩形信号定义为[19]：

$$H(\omega) = \begin{cases} T & |\omega| < \frac{1}{2T} \\ 0 & \text{其他} \end{cases} \tag{2.81}$$

对矩形信号取逆傅里叶变换将得到sinc信号

$$h(t) = \text{sinc}\left(\frac{t}{T}\right) \tag{2.82}$$

在(2.82)中改变变量t = kT得到

$$h(t) = h(kT) = \text{sinc}\left(\frac{kT}{T}\right) = \text{sinc}(k) \tag{2.83}$$

由于这里k是整数，根据(2.80)，我们可以继续将(2.83)写为

$$h(t) = h(kT) = \text{sinc}\left(\frac{kT}{T}\right) = \text{sinc}(k) = \begin{cases} 1 & k = 0 \\ 0 & k \neq 0 \end{cases} \tag{2.84}$$

将(2.84)与(2.78)比较，我们可以容易地发现，如果令t = kT，sinc脉冲恰好满足2.7.4节中的奈奎斯特脉冲成形理论。换言之，通过选择kT处的采样时间（采样频率等于1/T），我们的采样时刻位于等间隔的零交叉处，如图2.51(b)所示，因此不会有码间干扰。

回顾2.2.3节中的奈奎斯特采样定理指出，带宽限制在B Hz的实信号x(t)可以使用最小采样频率Fₛ = 2B Hz无差错地重建。在这种情况下，最小采样频率为Fₛ = 1/T Hz。因此，对应的最小带宽为

$$B = \frac{F_s}{2} = \frac{1}{2T} \tag{2.85}$$

这正是(2.81)中定义的矩形信号的带宽。基于上述讨论，这种sinc脉冲h(t)的选择产生最小带宽B = B_min = 1/(2T)，因此它被称为奈奎斯特I型脉冲[20]。

sinc脉冲是一个非常有吸引力的选择，因为它们在时间上宽、在频率上窄，这意味着它们同时具有频谱效率和无ISI的优势。然而，sinc脉冲不实用，因为它们由于定时误差而具有ISI敏感性。例如，对于大的t，(2.82)中定义的sinc脉冲具有以下近似：

$$h(t) \sim \frac{1}{t} \tag{2.86}$$

因此很明显，定时误差可能导致大的ISI。我们还必须注意，sinc脉冲在时间上是无限的，使得它们不可实现。

因此，我们需要引入奈奎斯特II型脉冲，它具有更大的带宽B > B_min，但ISI敏感性更低。由于这种类型的脉冲更实用，它在实践中被更广泛地使用。

升余弦脉冲是最重要的奈奎斯特II型脉冲之一，其频率传递函数定义为

$$H_{RC}(f) = \begin{cases} T & 0 \leq |f| \leq \frac{1-\beta}{2T} \\ \frac{T}{2}\left[1 + \cos\left(\frac{\pi T}{\beta}\left(|f| - \frac{1-\beta}{2T}\right)\right)\right] & \frac{1-\beta}{2T} \leq |f| \leq \frac{1+\beta}{2T} \\ 0 & |f| \geq \frac{1+\beta}{2T} \end{cases} \tag{2.87}$$

其中β是滚降因子，取值从0到1，β/(2T)是 excess 带宽。

升余弦脉冲的频谱如图2.52所示。一般来说，它具有带宽B ≥ 1/(2T)。当β = 0时，带宽B = 1/(2T)，没有 excess 带宽，这实际上是一个矩形脉冲。另一端，当β = 1时，达到最大带宽B = 1/T。

通过对H_RC(f)取逆傅里叶变换，我们可以获得升余弦脉冲的冲激响应，定义为

$$h_{RC}(t) = \frac{\cos\left(\frac{\pi \beta t}{T}\right)}{1 - \left(\frac{2\beta t}{T}\right)^2} \text{sinc}\left(\frac{\pi t}{T}\right) \tag{2.88}$$

奈奎斯特II型脉冲没有ISI敏感性，因为其峰值失真（h_RC(t)的尾部）快速收敛，可以表示为

$$D_p = \sum_{n=-\infty}^{\infty} |h_{RC}(\epsilon' + (n-k))| \sim \frac{1}{n^3} \tag{2.89}$$

因此，当发生定时误差时，失真不会以与奈奎斯特I型脉冲类似的方式累积到无穷大[20]。

实际上，在许多实际通信系统中，通常使用根升余弦滤波器[21]。如果我们将通信信道视为理想信道，并假设发射滤波器和接收滤波器相同，我们可以对两者都使用根升余弦滤波器，它们的净响应必须等于(2.87)中定义的H_RC(f)。由于等效信道的冲激响应可以表示为

$$h(t) = h_T(t) * h_C(t) * h_R(t) \tag{2.90}$$

其中h_C(t)是通信信道的冲激响应，h_T(t)和h_R(t)是发射滤波器和接收滤波器的冲激响应，这意味着在频域中，我们有

$$H_{RC}(f) = H_T(f)H_R(f) \tag{2.91}$$

因此，根升余弦滤波器的频率响应必须满足

$$|H_T(f)| = |H_R(f)| = \sqrt{|H_{RC}(f)|} \tag{2.92}$$

## 2.8 本章小结

SDR实验既需要强大的计算机技能，也需要广泛的数字信号处理知识。本章列出了一些有用的主题，包括采样、脉冲成形和滤波。本章的目的是帮助读者为实验章节做好准备，特别是Pluto SDR硬件。例如，在Pluto SDR发射路径上（见图2.53），有一个可编程的128抽头FIR滤波器、插值半带滤波器、DAC，随后是两个低通模拟重建滤波器（LPF）。为了理解这些如何协同工作并正确配置，你需要理解采样理论。

在Pluto SDR接收路径上（见图2.54），信号流过抗混叠滤波器、ADC、数字抽取半带滤波器，最终是一个128抽头可编程FIR，其中滤波知识很有用。这个128抽头可编程FIR可用于补偿由于抗混叠滤波器导致的通带损耗。

此外，当你构建真实的通信系统时，你将需要额外的发射和接收滤波器，这需要脉冲成形方面的专业知识。
