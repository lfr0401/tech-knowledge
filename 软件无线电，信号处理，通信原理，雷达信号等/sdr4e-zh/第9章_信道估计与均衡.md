# 第9章 信道估计与均衡

本章将介绍信道估计和信道均衡的概念。将讨论简化的误差模型以及向通信系统添加均衡器的几种实用策略。具体来说，我们将包括判决导向和基于训练的均衡设计。均衡器是有用的工具，因为它们可以用于处理环境中存在的许多失真源以及节点本身之间的失配。

关于我们在图9.1中的接收机轮廓，本章将处理最后一个块，均衡，它被突出显示。

## 9.1 你不可多径！

在前面的章节中，我们专注于发射机和接收节点之间的同步。通过结合前面的章节，帧恢复现在成为可能，我们已经达到了成功解码帧的门槛。然而，在某些场景下，这些实现将是不够的。假设我们有足够的接收信号SNR，环境中剩余的挑战是多径和其他加性干扰。多径由信道的色散特性引入，是沿不同路径到达接收机的传输信号的缩放反射的效应。由于这些反射沿不同路径传播，从接收机的角度来看，它们将经历不同的衰减和不同的延迟。自然地，这些损伤可以被认为是传输信号的回波，并且可以容易地由FIR滤波器建模。

第一接收信号和最终接收回波之间的时间定义为信道的延迟扩展[1]。在图9.2和9.3中，我们呈现了多径的物理表示以及视线（LOS）信号和两个散射体的所得时域表示。这是多径的射线追踪表示，但实际上多径是由于信号辐射特性导致的反射连续体。射线追踪是该连续体的离散化，通常用于建模多径，因为它更容易理解和数学建模。

当延迟扩展相对于信号带宽具有长持续时间时，多径效应可能对接收信号造成显著失真，并导致如第6章中讨论的码间干扰（ISI）。延迟扩展是环境的函数，我们在设计系统时必须考虑到这一点。例如，对于多径距离大的室外环境，这将产生大的延迟扩展。数学上，我们可以将散射体必须传播的距离D与该距离相关联的采样延迟t_s相关联为

$$t_s = \frac{B \times D}{c} \tag{9.1}$$

其中c是光速。20 MHz的Wi-Fi信号必须额外传播约15米才能导致单个采样的延迟。因此，通常在室内使用的Wi-Fi将具有小的延迟扩展。然而，由于信道距离短，可能存在大量高功率散射体。由于路径损耗，干扰信号的功率和延迟扩展通常成反比。

数学上，我们可以将接收的多径信号r建模为在随机时间偏移Δ_n处具有相关增益α_n的传输信号x的脉冲序列

$$r(t) = \mu(t) + \sum_{n=1}^{N} \alpha_n x(t - \Delta_n) \tag{9.2}$$

其中有N−1个散射体，μ是额外的干扰或噪声。只要μ与x不相关并且是周期性的或自回归的，我们就可以有效地从信号空间中过滤它[2]。在我们确实有多径的情况下，这将在接收端被体验为ISI。我们可以在图9.4中演示这样的条件，在那里我们查看QPSK信号r。在图9.4中，我们观察到符号随时间拖尾的效应，我们在星座图中查看为符号漂移。基于(9.2)，我们可以简单地使用FIR滤波器建模多径效应。

## 9.2 信道估计

在我们考虑校正给定信道的效应之前，我们可以替代地考虑未知信道的估计。与信道均衡不同，信道估计是一个理想的起点，因为我们在仿真中有已知的解决方案可以测试，这与均衡不同，均衡可能不会根据信道和噪声条件产生唯一的解决方案。为了执行信道估计，我们将利用由Widrow和Hoff开发的最小均方（LMS）算法[3]。LMS是梯度下降或牛顿方法类型的算法，可以被认为是信号处理的标准自适应滤波器算法。

LMS算法利用传输序列中的已知信息或符号来估计接收数据的损坏，我们在这里将其建模为FIR滤波器。我们在图9.5中提供了信道估计的常见图模型，我们将用它来帮助推导我们的系统实现。确实存在替代的自适应滤波器算法，例如递归最小二乘（RLS）算法，它在许多情况下可以优于LMS。然而，RLS在设计不当时可能存在稳定性问题，并且由于矩阵求逆要求而计算更复杂。RLS超出了本章的范围，但Haykin [4]是一个很好的参考。

我们在图9.5中说明了我们的信道估计系统的各部分，其中我们有影响我们训练数据x(t)的未知静态信道h。图9.5中所示系统的目标是匹配h和ĥ，这将把我们的误差驱动到零。为了实现这个目标，自适应算法将需要误差信号e(n)和原始信号x(t)。我们将利用LMS来估计未知信道滤波器h ∈ {L×1}，其估计定义为ĥ ∈ {M×1}，其中M ≥ L。对于通过信道滤波器h的传输信号x(t)，h可以使用以下递归算法估计：

$$y(n) = \hat{h}^H(n)x(n) \tag{9.3}$$
$$e(n) = r(n) - y(n) \tag{9.4}$$
$$\hat{h}(n+1) = \hat{h}(n) + \mu x(n)e^*(n) \tag{9.5}$$

其中

$$x(n) = [x(n), x(n-1), \ldots, x(n-M-1)]^T \tag{9.6}$$

μ是控制步长，提供对收敛速率和稳定性的控制。步长的选择是实现特定的，但应该在范围0 < μ < 2/λ_max内，其中λ_max是真实信道R = E[hh^H]的自相关的最大特征值。或者，由于h是未知的，更宽松和更安全的界限是Mσ²，其中σ²是r(n)的方差。关于LMS稳定性分析的更多信息，感兴趣的读者应该查阅Haykin [4]的第9章。

信道长度L对于单个环境是未知的，但通过测量和信道环境的物理性质，可以对合理的长度进行估计。这与之前关于延迟扩展的讨论相关，延迟扩展是信道长度的替代描述。标准委员会通常进行研究，以为接收机设计者提供指导。

方程(9.3)到(9.6)可以在代码9.1的第8-17行中以简单的递归实现，需要2L+1次乘法和L+1次加法。如果我们在图9.6中的解空间轮廓上检查L = M = 2时ĥ随时间的均方误差（MSE），我们可以观察到LMS将采取的到真实解的下降。图9.6演示了估计ĥ的四个随机起始位置的这种下降。轮廓图的使用是自适应滤波器理论中常见的分析工具，用于建模估计演化的行为。然而，当M > 2时，我们将使用类似于图9.7的MSE图，因为我们不能容易地在轮廓上可视化所有误差维度。

我们可以进一步扩展代码9.1，实际上也可视化信道估计的形状，以更好地理解我们设计的系统的准确性。检查响应，特别是对于相当激进的信道，在确定均衡器设计的参数化时可能非常有用。在代码9.2中，我们提供了如何可视化信道响应及其估计的例子。这里利用了函数freqz，它将使用fft函数计算数字滤波器响应。

图9.8中提供的响应和估计产生了非常准确的结果。然而，随着噪声被引入系统并且信道变得更复杂，这个估计将变得更差。然而，假设LMS算法已经收敛，误差应该仅基于我们选择的步长μ和信道的噪声而受限。

## 9.3 均衡器

与信道估计不同，均衡器试图撤销信道的影响并在可能的情况下移除干扰。与信道估计类似，关于源数据的一些知识对于在接收机处训练均衡器以减少信道效应是必要的。通常，此信息是帧的前导码序列或头部信息的一部分，因为对于逻辑操作，我们将总是传输一些未知数据，我们称之为有效载荷。我们将在这里讨论几种自适应均衡器实现，但文献中确实存在许多排列和替代方案[5]。

均衡器从与9.2节中讨论的不同的角度处理滤波器演化问题。不是演化滤波器以匹配信道h，而是演化滤波器f以补偿信道本身并在滤波器的输出处准确地再现训练数据。这种排列在图9.9中提供，它将均衡器滤波器或前向滤波器放置在接收数据路径中。然后已知的传输数据用于适配这个滤波器。为了使用LMS求解将均衡给定信道h效应的滤波器f ∈ {K×1}，我们需要修改(9.3)到(9.6)中提供的递归为

$$\hat{x}(n) = f^H(n)r(n) \tag{9.7}$$
$$e(n) = x(n) - \hat{x}(n) \tag{9.8}$$
$$f(n+1) = f(n) + \mu e^*(n)r(n) \tag{9.9}$$

其中：

$$r(n) = [r(n), r(n-1), \ldots, r(n-K-1)]^T \tag{9.10}$$

在这种情况下，我们正在驱动接收采样r(n)以匹配传输数据x(n)。如果该算法收敛，组合滤波器的所得输出应该只是延迟信号：

$$x(n) * h * f = \hat{x}(n-\delta) \tag{9.11}$$

其中*表示卷积运算，δ表示级联信道滤波器和均衡器的群延迟。因此，均衡器和信道的组合响应应该是平坦的。更新的代码在代码9.3中提供。

延迟δ将训练序列进一步偏移到滤波器中，如果最早的滤波器抽头不产生最大增益，这很有用。可以认为这更有效地利用了均衡器相对于信道长度的额外抽头优势。由于这个均衡器必须是因果的，δ > 0，否则我们将需要未来采样的知识（非因果）。此外，这个延迟将影响输出延迟，我们也必须对此进行补偿。要正确评估信号中的比特错误，使用代码9.4。

当我们有源符号的精确知识时，LMS是达到给定信道的维纳解的有效算法[4]。然而，在许多情况下，将不可能使用训练信息，而是将需要盲均衡技术。当接收信号不包含已知前导码或当均衡器更新想要在帧的有效载荷部分期间更新时，需要盲均衡。当信道具有长滤波器长度或需要比前导码中提供的更多数据时，这样的实现是必要的。或者，对于信道相干性短于帧的高动态信道，可能需要更新均衡器以维持期望的BER。在这里，我们将考虑判决导向（DD）LMS均衡器，尽管存在其他实现，例如恒模（CM）均衡器，有时称为色散最小化（DM）算法[6]。

DD均衡器通过对接收数据做出硬判决来操作，以估计最可能的符号并基于此估计更新均衡器。更新的均衡器结构在图9.10中提供，它在均衡器的输出之后插入判决块。因此，除了调制方案之外，接收机从这种设计中没有x(n)的知识。这导致(9.12)中的误差项在DD的情况下被更新为

$$e(n) = \hat{x}(n) - \bar{x}(n) \tag{9.12}$$

其中x̄(n)是均衡接收信号x(n)的最大似然估计。对于BPSK和QPSK的情况，我们有以下估计器：

$$\bar{x}(n) = \begin{cases} \text{sign}(y(n)) & \text{如果BPSK} \\ \text{sign}(\text{real}(x(n))) + i \times \text{sign}(\text{imag}(x(n))) & \text{如果QPSK} \end{cases} \tag{9.13}$$

当x(n)和x̂(n)相对接近时，DD均衡可以是有效的，但是当差异很大时，DD均衡器可能表现不佳。或者，从第6章提供的角度来看，眼图的眼睛必须最初在某种程度上睁开，以便DD均衡有效地或在合理数量的符号内有效地反转信道。我们在图9.11(a)中提供了具有ISI的接收信号，图9.11(b)中是LMS均衡后的所得信号，图9.11(c)中是DD均衡后的所得信号。LMS实现在几百个采样内收敛，而DD均衡器大约需要2,000个采样才能睁开眼睛，仍然有显著量的噪声。LMS具有明显的优势，但与DD方法不同，需要精确源符号的知识。注意，两个均衡器利用相同的μ，均衡器的初始化等于

$$f_{LMS} = f_{DD} = [1, 0, \ldots, 0] \in \{K \times 1\} \tag{9.14}$$

f_DD不能初始化为全零。

### 9.3.1 非线性均衡器

到目前为止，我们只考虑了具有前向滤波器的均衡器，也称为线性均衡器。然而，也可以实现同时具有反馈和前馈滤波器的滤波器，我们在这里称之为判决反馈均衡器（DFE）。DFE中的反馈滤波器将产生从输出中减去的前馈滤波器的输出。这在图9.12中概述，它显示了两个滤波器及其更新路径。由于反馈滤波器只能估计后光标符号，它需要与前馈滤波器结合使用。收敛后，反馈滤波器包含与前馈滤波器卷积的信道冲激响应的估计。由于反馈滤波器利用这个复合输出，DFE可以补偿严重的幅度失真而不增加高度失真信道中的噪声。

我们通过添加新滤波器d ∈ {P×1}来更新我们之前的均衡器方程。为了使用LMS求解将均衡给定信道h效应的滤波器d，我们需要修改(9.3)到(9.6)中提供的递归为

$$\hat{x}(n) = f^H(n)r(n) - d^H(n)\bar{x}(n) \tag{9.15}$$
$$e(n) = \bar{x}(n) - \hat{x}(n) \tag{9.16}$$
$$f(n+1) = f(n) + \mu e^*(n)r(n) \tag{9.17}$$
$$d(n+1) = d(n) + \mu e^*(n)\bar{x}(n) \tag{9.18}$$

其中

$$r(n) = [r(n), r(n-1), \ldots, r(n-K-1)]^T \tag{9.19}$$

和

$$\bar{x}(n) = [\bar{x}(n), \bar{x}(n-1), \ldots, \bar{x}(n-P-1)]^T \tag{9.20}$$

这里x̄(n)将是x(t)的DD版本或当使用训练数据时是x(t)本身。同样，我们可以更新我们的MATLAB代码以利用这个新的反馈滤波器，这在代码9.5中提供。

注意，DFE实现可能更难调整，因为它包含两个滤波器。DFE实现也可以每个滤波器更新利用不同的步长，这可能使调整更易于管理。

## 9.4 接收机实现

对于将均衡器实际实现到我们的接收机结构中，我们有几种设计策略可以根据系统需求利用。要考虑的合理设计视角是均衡给定信道环境所需的训练数据量。这里有三个方面：信道长度、均衡器的收敛性和信道的动态性。训练数据通常限于前导码序列，并且选择的长度将基于L的最大值选择，这也决定了M的值。

当信道是动态的，意味着与帧长度相比它可以在小时间段内变化时，利用多个均衡器变得必要。例如，我们可以利用LMS均衡器用前导码序列最初睁开眼睛，然后在数据上我们可以利用DD均衡器维持睁开的眼睛（见图9.13）。如果不使用辅助均衡器，那么帧长度将需要缩短以满足相同的BER要求。然而，前导码必须足够长以允许均衡器的适当适配，这将取决于M和L的值。对于更大的均衡器，需要更多数据才能收敛，从而导致更长的前导码。

我们可以更新代码9.3中的源代码，对于BPSK的情况，通过一些简单的修改利用LMS和DD。在代码9.6中，我们简单地添加一个条件以在不同模式之间切换。

均衡器本身在系统中是非常有用的工具，不仅仅是补偿系统中的多径。它们也可以用于补偿频率偏移、定时失配，甚至帧同步错误。然而，均衡器必须以补偿这种条件的方式配置。例如，当处理载波偏移时，与第7章中的条件相比，这只能相对较小，μ应该增加以处理这种条件。由于均衡器本身只是一个滤波器，补偿频率偏移简单地将均衡器的抽头形成为等同于与载波相关联的瞬时相位的复增益。然而，这必须连续更新以补偿这种条件，迫使双重DD和训练数据实现。

当考虑定时补偿时，实现分数均衡器可能很有用，它在前馈滤波器上消耗多个采样。这使得均衡器多速率，但也类似于第6章中的定时补偿设计。在这种配置中，均衡器将能够跨符号加权或插值以准确校正接收信号中的延迟。除了分数定时偏移之外，通过利用我们的延迟变量δ，我们可以补偿帧同步期间的采样错误。只要期望的采样或帧开始采样在前馈滤波器内，我们就可以补偿不正确的初始估计。对于长度为L且δ = ⌊L/2⌋的前馈滤波器，我们应该能够补偿±δ的采样偏移。

## 9.5 本章小结

在本章中，我们介绍了信道估计和均衡的概念。我们围绕梯度下降算法LMS构建了几种均衡器设计，LMS是该领域的主导成本函数。我们提供了当训练数据可用时和当需要盲操作时实现均衡器的不同策略。最后，我们提供了关于接收机实现策略的讨论，这些策略结合了多个均衡器设计以及环境非理想性的不同用例。对于感兴趣的读者，基本线性均衡器设计、迫零均衡器和判决反馈均衡器的简要数学推导在附录C中可用。
