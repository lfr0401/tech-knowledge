# 附录C 均衡器推导

## C.1 线性均衡器

假设我们假设一个收发机模型，其中信息源产生幅度值 $I_n$，应用于无限冲激序列；即：

$$s(t) = \sum_{n=-\infty}^{\infty} I_n \delta(t - nT) \tag{C.1}$$

其中 $\delta(t)$ 是狄拉克δ函数。将发射脉冲成形滤波器 $h_T(t)$ 应用于信息信号 $s(t)$，我们得到发射机的输出信号：

$$v(t) = \sum_{n=-\infty}^{\infty} I_n h_T(t - nT) \tag{C.2}$$

然后通过以信道滤波器 $h_C(t)$ 和加性高斯白噪声信号 $z(t)$ 为特征的传播信道发送。信道滤波器的输出产生信号：

$$p(t) = \sum_{n=-\infty}^{\infty} I_n h(t - nT) \tag{C.3}$$

其中 $h(t) = h_T(t) * h_C(t)$ 是信道冲激响应。接收机截获的信号表示为：

$$r(t) = p(t) + z(t) = \sum_{n=-\infty}^{\infty} I_n h(t - nT) + z(t) \tag{C.4}$$

在接收机处，我们想要找到均方误差（MSE）的表达式并将其最小化。为了实现这个目标，我们选择接收滤波器 $h_R(t)$ 与 $h(t)$ 匹配，产生以下最优结果：

$$h_R(t) = h^*(-t) \tag{C.5}$$

这导致接收滤波器的输出等于：

$$y(t) = p(t) * h^*(-t) + z(t) * h^*(-t) = \sum_{n=-\infty}^{\infty} I_n g(t - nT) + z(t) * h^*(-t) \tag{C.6}$$

其中 $g(t) = h(t) * h_R(t)$，并且：

$$x(t) = \phi_h(t) = h(t) * h^*(-t) = \int_{-\infty}^{\infty} h(t + \tau) h^*(\tau) d\tau \tag{C.7}$$

假设 $v(t) = z(t) * h^*(-t)$，那么我们得到以下表达式：

$$y(t) = \sum_{n=-\infty}^{\infty} I_n x(t - nT) + v(t) \tag{C.8}$$

现在，让我们对接收滤波器的输出进行采样，使得：

$$y_k = y(kT) = \sum_{n=-\infty}^{\infty} I_n x((k-n)T) + v(kT) \tag{C.9}$$

$$= \sum_{n=-\infty}^{\infty} I_n x_{k-n} + v_k \tag{C.10}$$

注意，$x_k$ 被称为信道自相关。此外，由于 $h^*(t)$ 的滤波，$v_k$ 采样不是白噪声，这意味着 $E\{v_k v_{k+n}\} \neq \delta(n)$。在这些情况下，我们有几种方法来处理这种有色噪声。一种方法涉及为噪声序列 $v_k$ 找到 $E\{v_k v_l^*\}$。在这种方法中，我们知道 $v_k(t)$ 是高斯的，因为 $z(t)$ 是高斯的。此外，我们知道 $z(t)$ 是白噪声；即 $S_z(f) = N_0$。因此，如果 $E\{z^*(s) z(t)\} = N_0 \delta(t-s)$，我们可以如下求解 $E\{v_k v_l^*\}$：

$$E\{v_k v_l^*\} = \int_{-\infty}^{\infty} ds \int_{-\infty}^{\infty} dt \, h(t-lT) h^*(s-kT) E\{z^*(s) z(t)\} \tag{C.11}$$

$$= N_0 \int_{-\infty}^{\infty} dt \, h(t-lT) h^*(t-kT) \tag{C.12}$$

$$= N_0 \int_{-\infty}^{\infty} dt \, h(t + |k-l|T) h^*(t) \tag{C.13}$$

由于我们有：

$$x_k = \int_{-\infty}^{\infty} h^*(t) h(t + kT) dt \tag{C.14}$$

这然后给我们 $E\{v_k v_l^*\}$ 的表达式为：

$$E\{v_k v_l^*\} = N_0 x_{k-l} \tag{C.15}$$

然后可以写为 $v_k$ 的自相关函数和功率谱密度；即：

$$R_v(k) = E\{v_n v_{k+n}^*\} = N_0 x_k \tag{C.16}$$

$$S_v(z) = \mathcal{Z}\{R_v(k)\} = N_0 X(z) \tag{C.17}$$

处理有色噪声的第二种方法是实现一种称为白化滤波器的东西。在这种情况下，我们尝试逆转接收滤波器对噪声信号 $z(t)$ 的影响。换句话说，由于我们有 $v_k$ 的功率谱密度等于 $S_v(z) = N_0 X(z)$，我们最终希望白化噪声功率谱密度仅等于 $N_0$。为了实现这一点，我们假设 $x_k$ 的z变换 $X(z)$ 可以表示为以下形式：

$$X(z) = F(z) F^*(1/z^*) \tag{C.18}$$

因此，如果我们有一个传输函数等于 $1/F^*(1/z^*)$ 的白化滤波器，该白化滤波器输出处的所得功率谱密度应等于：

$$S_n(z) = \frac{1}{F(z) F^*(1/z^*)} S_v(z) = \frac{N_0 X(z)}{X(z)} = N_0 \tag{C.19}$$

这产生一个白噪声输出信号。

## C.2 迫零均衡器

假设我们假设接收机的离散时间模型等于以下形式：

$$w_k = \sum_{n=-\infty}^{\infty} I_n f_{k-n} + n_k \tag{C.20}$$

其中 $w_k$ 是白化滤波器的输出信号，$f_k$ 是白化滤波器的冲激响应，$n_k$ 是功率谱密度等于 $N_0$ 的白化噪声信号。

在迫零均衡器（ZFE）中，我们选择一个传输函数 $C(z)$，使得每个ISI补偿项 $q_k = \delta_k$，这意味着不存在ISI，并且所得的均衡输出 $I_k + n'_k$ 随后被量化，对于 $I_k = \pm 1$ 产生等于 $P_e = Q(1/\sigma')$ 的错误概率。虽然 $P_e$ 通常用作通信系统的性能指标，但在均衡器设计的情况下，我们将使用最小均方误差（MMSE）作为我们的指标；即 $E\{|I_k - \hat{I}_k|^2\}$。

假设我们对（C.20）取z变换，从而得到：

$$W(z) = I(z) F(z) + N(z) \tag{C.21}$$

一旦这被ZFE均衡器滤波，我们得到的输出等于：

$$W(z) C(z) = I(z) F(z) C(z) + N(z) C(z) \tag{C.22}$$

其中 $Q(z) = F(z) C(z)$。我们ZFE的目标是产生等于以下的输出：

$$\mathcal{Z}^{-1}\{W(z) C(z)\} = I_k * q_k + n'_k \tag{C.23}$$

其中 $q_k = \delta_k$；即信号中不存在ISI。因此，该表达式中的ISI项是 $F(z) C(z)$，因此我们希望它等于 $Q(z) = F(z) C(z) = 1$，对于 $q_k = \delta_k$。重新排列各项，我们的ZFE应等于 $C(z) = 1/F(z)$。

## C.3 判决反馈均衡器

虽然ZFE滤波器在概念上很简单，但它们几乎总是具有无限数量的抽头，因此使得它们在实际应用中无法实现。此外，当使用ZFE均衡白化滤波器输出处的信号时，均衡信号中包含的任何噪声贡献将不再是白噪声。因此，存在其他可以更容易在硬件中实现的均衡器设计。其中之一是判决反馈均衡器（DFE），它由两个滤波器组成：前馈滤波器 $a(z)$ 和反馈滤波器 $b(z)^{-1}$。

前馈滤波器 $a(z)$ 是反因果的，具有以下形式：

$$a(z) = a_{-1} z + a_{-2} z^2 + a_{-3} z^3 + a_{-4} z^4 + \ldots \tag{C.24}$$

而反馈滤波器 $b(z)$ 是因果滤波器，具有以下形式：

$$b(z)^{-1} = b_1 z^{-1} + b_2 z^{-2} + b_3 z^{-3} + b_4 z^{-4} + \ldots \tag{C.25}$$

因此，我们可以设计 $a(z)$ 和 $b(z)$，使得：

$$a(z) = C F^*(1/z^*) \tag{C.26}$$

$$b(z) = F(z) \tag{C.27}$$

$$F(z) F^*(1/z^*) = X(z) + N_0 \tag{C.28}$$
