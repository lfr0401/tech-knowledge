# 第7章 载波同步

本章将介绍发射和接收节点之间载波频率偏移的概念。具体来说，将讨论简化的误差模型以及两种恢复方法，这两种方法可以根据其实现联合或独立操作。载波恢复补充了在前一章第6章中实现的定时恢复，对于维持具有独立振荡器的无线电之间的无线链路是必要的。

在整个本章中，我们将假设发射和接收无线电之间的定时失配已经被校正。然而，这并非在所有情况下都是要求，特别是在这里提供的初始实现中，但对于所提供的最终实现的最佳性能将成为必要条件。为了简单起见，我们也将在仿真中忽略定时效应，除了讨论Pluto SDR本身时，因为显然在那种情况下定时校正不能被忽视。关于我们在图7.1中的完整接收机图轮廓，我们现在正在考虑载波恢复和CFO块。

## 7.1 载波偏移

接收和发射节点通常是两个不同且空间分离的单元。因此，由于诸如杂质、电噪声和温度差异等自然效应，它们的本振之间将存在相对频率偏移。由于这些差异也可能是相对动态的，本振将相对于彼此漂移。这些偏移可能包含随机相位噪声、频率偏移、频率漂移和初始相位失配。然而，为了简单起见，我们将仅将此偏移建模为固定值。在射频通信的时间尺度上，这是一个合理的假设。

当考虑商用振荡器时，频率偏移以百万分率（PPM）提供，我们可以将其转换为给定频率的最大载波偏移。在Pluto SDR的情况下，内部本振额定为25 PPM [1]（校准时为2 PPM），我们可以使用(7.1)将最大载波偏移Δf与我们的工作载波频率f_c相关联。

$$f_{o,\max} = f_c \times \frac{PPM}{10^6} \tag{7.1}$$

f_{o,\max}的确定很重要，因为它提供了我们的载波恢复设计标准。浪费资源来校正超出我们操作范围的频率是没有意义的。然而，在这种情况下可以使用扫描技术，但超出了本书的范围。

数学上，我们可以将基带处具有载波频率偏移f_o（或ω_o）的损坏源信号s(k)建模为

$$r(k) = s(k)e^{j(2\pi f_o kT + \theta)} + n(k) = s(k)e^{j(\omega_o kT + \theta)} + n(k) \tag{7.2}$$

其中n(k)是零均值高斯随机过程，T是符号周期，θ是载波相位，ω_o是角频率。

在文献中，载波恢复有时被定义为载波相位恢复或载波频率恢复。这些通常都具有在同步器输出处提供稳定星座的相同目标。然而，理解频率和相位的关系很重要，这将使这些命名约定清晰。角频率ω，或等效地频率2πf，纯粹是随时间变化的相位θ的度量：

$$\omega = \frac{d\theta}{dt} = 2\pi f \tag{7.3}$$

因此，恢复信号的相位本质上就是恢复该信号的频率。通过这种关系，是估计信号频率的常用方法，因为与相位不同，它不能直接测量。我们可以用代码7.1中所示的简单MATLAB脚本演示这种技术。在那里，我们生成给定频率的简单连续波（CW）音调，测量信号的瞬时相位，然后取这些测量的差值作为我们的频率估计。任何复信号x(k)的瞬时相位θ可以测量为

$$\theta = \tan^{-1}\left(\frac{\text{Im}(x(k))}{\text{Re}(x(k))}\right) \tag{7.4}$$

其中Re和Im分别捕获信号的实部和虚部。在代码7.1中，我们还通过希尔伯特变换使用函数hilbert从我们的实信号提供复正弦波生成。希尔伯特变换对于生成实信号的解析或复表示非常有用。如果你希望了解更多关于希尔伯特变换的知识，Oppenheim [2]是基于信号处理理论的推荐读物。

在图7.2中，我们提供了代码7.1的输出。在图7.2(a)中，首先可以观察到希尔伯特变换的输出等于从我们的正弦（虚部）和余弦（实部）信号生成的CW音调。在图7.2(b)中，我们可以清楚地看到基于相位差的估计技术正确估计了所讨论信号的频率。在这个脚本中，我们还利用了函数unwrap来防止我们的相位估计被限制在±π之间。这个估计是(7.3)中关系的直接应用。或者，检查频率偏移可能很有用，但通常只有大偏移，在频域本身中。这很有用，因为仅时域信号，特别是当包含调制数据和噪声时，可能难以解释这种偏移。在图7.3中，显示了原始和偏移信号的PSD，这清楚地演示了这个视角。在这里，信号相对于原始信号保持10 kHz的偏移，这完全在200 MHz以上通信的Pluto SDR的25 PPM规格内。

在频域中移动复信号是(7.2)的简单应用，图7.3(b)就是这样生成的。代码7.2中的示例MATLAB脚本演示了如何使用指数函数移动复信号。或者，如果需要，可以直接使用正弦波。在所提供的脚本中，重要的是首先对信号进行上采样或过采样，如代码7.2中的SRRC滤波器所执行的那样。这使得频移明显，因为主信号能量被限制在带宽的一小部分。

## 7.2 频率偏移补偿

有许多不同的方法来设计无线接收机，使用许多不同的恢复技术和算法排列。在本节中，我们将首先考虑频率偏移，然后继续管理剩余的同步任务。如10.3节所讨论的，Pluto SDR的振荡器额定为25 PPM。在诸如2.4 GHz的免许可频段中发射信号可能在无线电之间产生120 kHz的最大偏移。由于这是一个相当大的范围，我们将开发一种分为粗和精频率校正的两阶段频率补偿技术。这种设计是有利的，因为它可以减少估计相对载波的收敛或锁定时间。

### 7.2.1 粗频率校正

文献中有两类主要的粗频率校正：数据辅助（DA）和盲校正。DA技术利用相关类型结构，这些结构使用接收信号的知识，通常以前导码的形式，来估计载波偏移f_o。尽管DA方法可以提供准确的估计，但它们的性能通常受前导码长度的限制[3]，并且随着前导码长度的增加，这会降低系统吞吐量。

或者，盲或非数据辅助（NDA）方法可以在信号的整个持续时间内操作。因此，可以认为在现实系统中NDA可以优于DA算法。这些粗技术通常以开环方法实现，以便于使用。在这里，我们将概述并实现一种基于NDA FFT的粗补偿技术。这里应用的概念很简单，基于我们在图7.3中提供的初始检查，我们可以提供符号偏移的粗略估计。然而，直接从FFT取峰值不会非常准确，特别是如果信号在频率上不对称。为了补偿这个事实，我们将通过将信号提升到其调制阶数M来移除信号本身的调制分量。从我们在(7.2)中的模型，忽略噪声，我们可以观察到以下内容：

$$r^M(k) = s^M(k)e^{j(2\pi f_o kT + \theta)M} \tag{7.5}$$

这将把偏移移动到其原始位置的M倍，并使s(t)纯实或纯复。因此，s^M(t)项可以被忽略，只有剩余的指数或音调将保留。为了估计这个音调的位置，我们将取r^M(t)的FFT，并将具有最多能量的箱与这个音调的位置相关联。图7.4是从代码7.2生成的偏移10 kHz的BPSK信号的r^M(t)的示例频率图。正如预期的那样，峰值在该频率的两倍处清晰可见。形式上，这个频率估计可以写成单个方程[4]

$$\hat{f}_o = \frac{1}{2TK}\arg\left(\left|\sum_{k=0}^{K-1} r^M(k)e^{-j2\pi kT/K}\right|\right) \tag{7.6}$$

其中K是FFT长度。(7.6)中的估计被定义为粗，因为所得的f̂_o只能是FFT产生的K个值之一。然而，如果需要，我们可以通过在多个估计上跨固定的FFT箱集进行插值来扩展这种准确性。信号的每个FFT箱的频率分辨率简单地是

$$f_r = \frac{1}{MTK} \tag{7.7}$$

因此，我们可以通过增加FFT大小或通过降低系统的采样率来增加我们估计器的性能。然而，不要将采样降低到低于感兴趣信号的带宽。

在MATLAB中实现这种方法很简单，为了效率，K应该总是以2为底的数字，以便FFT的效率。在代码7.3中，我们为每K个数据采样产生一个估计，并补偿来自fft函数的频率排列。当使用这种技术时，我们还应该考虑系统的其他方面或这个操作可能产生的影响。从下游算法的角度来看，它们将每K个采样观察到一次频率校正。理想情况下，f̂_o保持恒定，但如果偏移接近FFT箱边界，这不太可能。结果是信号中相对于先前信号的±f_r频率跳跃。不幸的是，这些突然变化可能会破坏下游的反馈算法，这些算法没有准备好处理它们正在估计/校正的信号的频率或相位的突然偏移。为了对抗这一点，我们有两个主要策略。首先，估计可以随时间用滤波器平均，随时间平滑变化。第二个选择是仅在帧的开始处应用此校正。由于偏移在合理大小的帧上应该是相对静止的，单个测量在该时间段内应该是准确的。这种校正也被认为是粗的，因为它只能准确到f_r以内，这仅强制执行这种类型的校正间隔。

话虽如此，这种基于FFT的技术的一个弱点是它需要大量数据才能进行合理估计。当在发射机处用发射滤波器进行过采样时，这种技术也会产生不纯的音调。然而，诸如来自Luise [5]的其他技术被设计用于突发型应用，其中相对于上述FFT方法需要更少的数据。不幸的是，与FFT方法不同，Luise方法是有偏估计器。

### 7.2.2 精频率校正

在粗频率校正（CFC）之后，基于所选择的配置分辨率f_r，仍将存在偏移。精频率校正（FFC），也称为载波相位校正，应该为最终解调产生稳定的星座。本质上，这将把接收信号的剩余频率偏移驱动为零。我们可以将这种校正描述为产生稳定的星座，因为精频率偏移效应通常是用星座图检查的。如果离散数字调制信号表现出频率偏移，这将导致随时间的旋转，如在星座图中检查的那样。在图7.5中，我们演示了这种效应，其中每个数字关联采样在时间上的相对出现，这提供了这种旋转的视角。信号本身是BPSK，导致它以不同的源符号跨越原点跳跃。如果应用正频率偏移，旋转将是逆时针的，负偏移则是顺时针的。旋转速率等于频率偏移，这就是我们的ω（角频率）概念的来源，如先前在(7.3)中定义的。

这种偏移也可以用Pluto SDR以类似的方式观察到。在图7.6中，我们在环回中发射了BPSK信号，发射和接收本振之间有1 kHz的差异。我们在图7.6(b)中观察到与图7.5类似的旋转。为了正确地可视化这种效应，我们需要执行定时校正，这是从第6章借用的。没有定时校正，信号很难从星座图中解释，如图7.6(a)中观察到的那样。由于在这种情况下在频率校正之前执行了定时校正，这需要使用6.4.1节中详述的Gardner技术。与使用前馈技术的CFC不同，对于FFC，我们将利用如第4章中检查的基于PLL理论的反馈或闭环方法。该算法的结构在图6.11中提供，源自[6, 第7章]，这与我们在图6.11中的原始轮廓相关。

这种全数字基于PLL的算法通过首先在相位误差检测器（PED）中测量接收采样的相位偏移来工作，我们称之为误差信号e(n)。PED基于期望接收星座/符号的结构设计。接下来，环路滤波器帮助管理整个PLL的动态。环路滤波器可以确定操作频率（有时称为拉入范围）、锁定时间和PLL的响应性，以及平滑误差信号。最后，我们有直接数字合成器（DDS），其名称是带有压控振荡器（VCO）的模拟PLL设计的遗留物。DDS负责为输入生成校正信号，该信号又将被反馈到系统中。在FFC设计的情况下，这个PLL应该最终产生期望偏移等于零的输出信号。

从PED开始，这个块的目标只是测量输入复数据相对于期望参考星座的相位或径向偏移。通过参考以及扩展e(n)，我们实际上指的是距星座基的距离。在QAM、PSK和PAM的情况下，这些将始终是实轴和虚轴。然而，你可能需要关于FSK或其他调制方案扩展这个视角。这个想法背后的主要推理是它将移除特定维度中的缩放方面，而是考虑特定基中能量或幅度的比率。为了更好地理解这个概念，让我们考虑QPSK，它具有以下PED方程：

$$e(n) = \text{sign}(\text{Re}(y(n))) \times \text{Im}(y(n)) - \text{sign}(\text{Im}(y(n))) \times \text{Re}(y(n)) \tag{7.8}$$

在(7.8)中，e(n)本质上测量y(n)的实部和虚部之间的差异，并且仅当Re(y(n)) = Im(y(n))时才为零。你会注意到这将仅迫使输出星座到特定方向，但不是特定范数值。然而，如果y(n)需要不同的方向，这可以在通过同步器后通过简单乘以期望的相移φ_POST来完成，如

$$y_{SHIFT}(n) = y(n)e^{j*\phi_{POST}} \tag{7.9}$$

注意y_SHIFT(n)不应该被馈入PED。

在其他调制方案的情况下，PED误差估计将基于期望的信号排列而改变。例如，BPSK或PAM将具有以下误差估计：

$$e(n) = \text{sign}(\text{Re}(y(n))) \times \text{Im}(y(n)) \tag{7.10}$$

这个PED误差函数再次具有仅为y(n)的方向提供误差信号的相同目标。对于(7.10)，仅当y(n)纯实时e(n)才为零。

(7.8)和(7.10)背后的推理很简单。另一方面，所有PLL设计中的环路滤波器是最具挑战性的方面，但它提供了对系统适应的最多控制。同样在这里，我们将使用PI滤波器作为我们的环路滤波器，这在6.3.1节中详述。这个FFC同步器的最后一块是DDS，它只是一个积分器。由于环路滤波器产生控制信号，该信号等同于输入信号的频率，因此有必要改为提取该信号的相位。这里用于积分器的传递函数是

$$D(s) = G_3\frac{1}{s} \rightarrow D(z) = G_3\frac{z^{-1}}{1-z^{-1}} \tag{7.11}$$

注意，我们在离散域中添加了单个采样的额外延迟，并且由于我们正在产生校正信号，G_3 = −1。同样，这个积分器可以用双二阶滤波器实现。

在图7.7中所示的PLL的这种排列中，系统应该产生输出y(n)，其具有最小的相位和频率偏移。再次在图7.7中绕环路，PED将首先产生等于与观察到的校正符号y(n)相关联的相位偏移的误差，然后环路滤波器将关联这个观察到的误差并将其与所有先前误差加权。最后，DDS将加权误差/控制信号f(n)转换为相位φ(n)，我们用它来校正下一个输入采样x(n+1)。在频率偏移的情况下，φ将连续变化，因为它是相位值，而不是频率值。然而，如果输入信号太动态或滤波器的增益设置不当，PLL将无法跟上x的变化相位（频率）。

对于环路滤波器增益值（G₁, G₂）的计算，利用基于优选阻尼因子ζ和环路带宽B_Loop的以下方程：

$$\theta = \frac{B_{Loop}}{M(\zeta + 0.25/\zeta)}$$
$$\Delta = 1 + 2\zeta\theta + \theta^2 \tag{7.12}$$
$$G_1 = \frac{4\zeta\theta/\Delta}{MK}$$
$$G_2 = \frac{(4/M)\theta^2/\Delta}{MK} \tag{7.13}$$

其中M是每符号采样数，K是检测器增益。对于QPSK和矩形QAM，K = 2，但对于PAM和PSK，K = 1。注意B_Loop是归一化频率。如果你对这些是如何推导的感兴趣，查阅[6, 附录C]以获得完整详细分析。对于ζ的选择，参考回6.3.1节，这里有相同的定义。B_Loop的选择应该与期望的最大估计归一化频率锁定范围Δf,lock range相关：

$$\Delta f_{,pull} \sim 2\pi\sqrt{2}\zeta B_{Loop} \tag{7.14}$$

注意，这个值是基于PLL线性化模型的估计。因此，在仿真版本中可能存在不一致。然而，当正确配置时，即使在强噪声条件下，这种PLL设计也应该表现良好。与CFC校正不同，这个FFC通常不会有相同的操作范围。在你的设计中，从阻尼因子ζ = 1和环路带宽B_Loop = 0.01开始可能很有用。根据经验，在这里使用过阻尼系统是优选的，因为它直接增加了拉入范围。然而，环路收敛将需要更长时间。

我们现在拥有实现FFC同步器所需的所有部分，我们在代码7.4中提供了完整的参考实现。然而，讨论一些设计考虑很重要。首先，我们已经声明FFC同步器的输出可以具有输出星座特定方向的目标，这完全由PED确定。然而，同步器可能并不总是能够实现这个目标星座方向，这意味着星座可能看起来稍微旋转或出现在预期位置的倍数处。这将由具有比FFC配置处理的更大载波偏移的信号导致，或最显著地当系统以欠阻尼方式配置时。或者，如果接收信号具有差的SNR，这也将降低同步器的有效拉入范围或导致不期望的锁定位置。这在代码7.4中说明，其中使用了两种不同的ζ配置。系统也被驱动到接近配置的估计最大偏移。通常，这些估计将是保守的，并且需要针对特定调制方案、SNR和环路滤波器配置进行经验测试。然而，在这种情况下，如果我们检查图7.8中的收敛信号，我们注意到一组有趣的结果。在图7.8(b)中，星座实际上收敛到错误的最小值。这是PLL动态的结果，它处于欠阻尼状态。迫使系统更刚性将提供正确的结果，如图7.8(a)中。然而，如果ζ太大，同步器将不会收敛或可能需要很长时间才能这样做。

当实现和测试你自己的系统时，实际测量同步器本身的频率估计可能很有用。由于我们知道DDS φ的输出是下一个符号所需的瞬时相位校正，我们可以简单地应用(7.3)，使用与代码7.1中类似的计算。从角频率估计，我们可以将其转换为更有形的赫兹频率估计，如(7.3)中。通过检查代码7.4的相位（φ）的导数，我们可以检查对于fs = 1000 Hz时20 Hz偏移的估计的收敛。在图7.9中，我们绘制了f_est，其中在正确值周围有明显的收敛。然而，由于信号包含噪声并且PLL存在固有噪声，估计将不是静态的。这在真实系统中很有用，因为发射和接收本振之间的偏移将始终相对于彼此是动态的。

### 7.2.3 性能分析

为了评估同步性能，可以考虑许多变量。这些包括但不限于锁定时间、有效拉入范围和收敛误差矢量幅度（EVM）。这些指标应该以满足特定设计需求的方式进行平衡，因为它们将相互冲突。例如，设计具有快速锁定时间的系统可能很简单，但它可能具有有限的拉入范围。这与(7.14)和来自[6, 附录C]的二次测量直接相关，其定义了归一化频率锁定延迟：

$$t_{\Delta,Max} \sim \frac{32\zeta^2}{B_{Loop}} \tag{7.15}$$

如果我们直接关注来自PED的误差信号，我们可以演示ζ和B_Loop之间的这种权衡。通过将归一化载波偏移固定为0.01、ζ = 1.3并为B_Loop选择两个不同的值来修改7.4中的代码，我们可以在图7.10中观察到e(n)。在B_Loop的两种配置中，归一化偏移都小于Δf,pull。在B_Loop = 0.24的情况下，系统在几十个采样内收敛到解决方案，而B_Loop = 0.03的情况慢一个数量级。然而，对于B_Loop = 0.03的情况，收敛误差信号的方差σ²_e小三倍。这个误差将表现为y(n)上的相位噪声，这将影响信号的解调正确性。

### 7.2.4 误差矢量幅度测量

评估y(n)的EVM将提供恢复信号中这种相位噪声的度量。EVM是理解系统中算法性能的非常有用的测量。EVM测量星座相对于参考位置的残余误差。要计算百分比RMS的EVM，我们可以使用以下方程：

$$EVM_{RMS} = 100 \times \sqrt{\frac{\sum_{k=0}^{N-1} e_{const}(k)}{\sum_{k=0}^{N-1} (\text{Re}(\bar{y}(k))^2 + \text{Im}(\bar{y}(k))^2)}} \tag{7.16}$$

其中

$$e_{const}(k) = (\text{Re}(y(k)) - \text{Re}(\bar{y}(k)))^2 + (\text{Im}(y(k)) - \text{Im}(\bar{y}(k)))^2 \tag{7.17}$$

而ȳ(k)是y(k)的参考符号。EVM是接收信号分散性的度量。因此，EVM值越低越好。在某些情况下，以分贝计算EVM可能很有用，可以从(7.16)转换为

$$EVM_{dB} = 20\log_{10}\left(\frac{EVM_{RMS}}{100}\right) \tag{7.18}$$

以分贝计算EVM在OFDM标准中非常常见，因为可能正在发射的高阶星座需要显著的EVM余量才能恢复。为了方便，通信系统工具箱包含一个称为comm.EVM的系统对象，为我们提供这些计算。

## 7.3 相位模糊

载波同步要考虑的最后一个主题是相位模糊。相位模糊源于这里概述的FFC同步器对发射信号的真实方向是盲目的这一事实。对于给定的对称调制方案，可能存在许多收敛方向，这可以与调制阶数相关。例如，PAM将有两个可能的方向，QPSK和矩形QAM将有四个，而MPSK将有M个可能的方向。然而，有许多解决方案来补偿这个问题，包括码字、使用具有训练数据的均衡器和差分编码。每种实现有不同的用例。

### 7.3.1 码字

使用码字是解决相位模糊的常见做法，它依赖于接收数据中的已知序列。这通常只是前导码本身，它将存在于每个帧中并且在接收机处已知。如果需要，这种策略可以在解调之前或之后使用。如果在解调后执行，输出位必须重新映射到它们的真实位置。这个过程最好通过例子解释。考虑源字w和相关的QPSK符号s：

$$w = [1, 0, 3]$$
$$s = [(-1, 1i)\ (1, 1i)\ (-1, -1i)] \tag{7.19}$$

可能的接收符号将是

$$s_1 = [(-1, 1i)\ (1, 1i)\ (-1, -1i)]$$
$$s_2 = [(-1, -1i)\ (-1, 1i)\ (1, -1i)]$$
$$s_3 = [(1, -1i)\ (-1, -1i)\ (1, 1i)]$$
$$s_4 = [(1, 1i)\ (1, -1i)\ (-1, 1i)] \tag{7.20}$$

解调每个码字符号并与预期结果比较将提供正确解调剩余数据符号所需的映射。对于实现，解调所有前导码符号并取最常见的方向映射可能很有用，因为依赖单个符号可能容易出错。

或者，可以直接测量来自正确方向的相位偏移θ_p，其中p是接收的前导码符号，p_r是参考或真实前导码符号，所需的校正简单地是

$$\theta_p = \tan^{-1}\left(\frac{\sum_n \text{Im}(p(n)^* \times p_r(n))}{\text{Re}(p(n)^* \times p_r(n))}\right) \tag{7.21}$$

假设p(n)具有期望的方向。然后剩余信号y将被校正为

$$y_c = y e^{-j\theta_p} \tag{7.22}$$

### 7.3.2 差分编码

处理相位模糊的第二个选择是对源位本身进行差分编码。这里的目标是使真实数据依赖于连续位之间的差异，而不是接收位本身。为了编码源数据，我们在发射机处应用以下内容：

$$b_t(n) = b_t(n-1) \oplus b(n) \tag{7.23}$$

其中b_t是发射的编码位，b是未编码位，⊕是模二加法。为了解码信号，我们基本上反向执行(7.23)为

$$b(n) = b_t(n) \oplus b_t(n-1) \tag{7.24}$$

通常在这种方案中，第一位被忽略，因为它仅基于自身，而不是两个连续位之间的差异。工程师可能会指出这是浪费，但这减少了与用符号测量偏移相关的任何复杂数学，并且仅需要位级操作。这也可以由于位错误的传播而降低接收信号的误码率。

### 7.3.3 均衡器

第三个流行选择是依靠均衡器为系统校正这种模糊。使用训练数据，均衡器可以学习并校正这种相移，这本质上只是一个复数乘法。均衡器将在第9章中详细讨论。然而，如果信道校正或同步也不由均衡器执行，这对于均衡器实现来说是一个小任务。

## 7.4 本章小结

在本章中，我们讨论并提供了载波偏移的模型及其与接收机操作的关系。从这个模型，我们提供了两种补偿载波偏移的方案，包括粗和精恢复算法。然而，如果需要，确实存在可以联合执行定时和载波恢复的其他实现[6]。我们已经检查了这些算法如何在系统级使用，以及如何评估单个性能。这些包括它们参数化的表征以及恢复数据上的度量。总之，当在具有独立本振的两个不相交节点之间传输数据时，载波偏移补偿是一种必要的同步技术。
